Zscaler ThreatLabz identified C2Looper in July 2026 as a new Rust-based malware family likely leveraged by a ransomware-related threat actor. ThreatLabz assesses with low to medium confidence that C2Looper has been delivered to victims through a multi-stage ClickFix infection chain. The malware supports backdoor commands for executing arbitrary commands, performing reconnaissance, and deploying second-stage payloads.

C2Looper uses string encryption and dynamically resolves Windows APIs at runtime with LoadLibrary and GetProcAddress. Older variants communicate with a command-and-control server over plaintext HTTP, sending host details such as username, DNS hostname, process identifier, and bot ID to the /api/beacon endpoint every second. Supported commands in older variants include ping, run, shell, upload, and download, including an upload command that saves a PE file as wtsapi32.dll under a OneDrive path and abuses a legitimate OneDrive executable to load the malicious DLL.

ThreatLabz also identified C2Looper version 2, which adds capabilities and uses GitHub for all command-and-control operations. This version stores command data, command output, and beacon information in cmd.json, result.json, and beacon.json files in a GitHub repository, and it creates a directory for each bot. C2Looper v2 adds commands such as ls, recon, drives, and inject, changes how upload, run, and shell operate, and fixes a task ID parsing bug present in the older variant.

  • C2Looper v2’s use of GitHub means command data, beacon data, and command results are stored as JSON files in a repository rather than sent to the older HTTP API endpoints.
  • The older C2Looper variant was observed downloading the newer version through its upload command, indicating the malware’s built-in update mechanism was used to move victims to the GitHub-based version.
  • C2Looper’s upload command abuses a legitimate OneDrive executable to load a malicious DLL named wtsapi32.dll from the OneDrive directory under %LocalAppData%.
  • C2Looper v2 fixed the older variant’s task ID parsing bug, so command results are now reported with the correct task ID.
  • The article notes that Oyster malware uses similar C2 API endpoints, which is noteworthy because Oyster is likely related to the threat actor behind Lactrodectus.
