Is This A Joke? In The Auth Header? (F5 BIG-IP UnAuth Heap-Overflow to RCE CVE-2026-94127)
labs.watchtowr.com · 23 Sep 2026 23:19 UTC openai-codex / gpt-5.6-terra

In plain words

Researchers examined a flaw in F5 BIG-IP APM, a widely used system that sits at the edge of company networks and helps direct web traffic and manage sign-ins. On affected versions, an attacker can send an overly long sign-in-related request without logging in, causing the device to crash and potentially take control of it. This matters because these devices can handle encrypted traffic and authentication for many applications, so a compromise could give an attacker a powerful position inside an organization’s network.

Summary
watchTowr Labs found that CVE-2026-94127 is an unauthenticated heap overflow in F5 BIG-IP APM OAuth endpoints, triggered by an oversized Authorization header and potentially enabling remote code execution. Affected BIG-IP APM deployments should apply F5’s hotfixes immediately.

watchTowr Labs analyzed CVE-2026-94127, a flaw in F5 BIG-IP Access Policy Manager (APM) OAuth functionality. F5’s advisory lists BIG-IP APM 21.1.0 and specified 17.x versions as affected, with hotfixes available for those branches. The issue is notable because BIG-IP devices can sit at the edge of a network, handling traffic, TLS termination, and authentication-related functions.

The researchers found that vulnerable code allocated a fixed 0x4100-byte heap buffer and copied an Authorization header value into it without checking its size first. The patch adds a check that rejects Authorization headers larger than 0x4100 bytes, and the researchers triggered a crash on an unpatched OAuth-configured system by sending an oversized Bearer Authorization header to an OAuth endpoint. They reported that, in many test runs, the overflow could overwrite a nearby callback function pointer; although SELinux blocked a direct shell launch, they described using a crash-triggered script to run a command.

  • The flaw is confined in F5’s advisory to BIG-IP APM, even though BIG-IP’s other modules and BIG-IQ Centralized Management are listed as not affected.
  • The vulnerable code allocated a fixed 0x4100-byte buffer and copied the Authorization header into it without first checking the header’s length, while the fix was a direct size check.
  • The article’s proof of concept required an OAuth profile to be configured and an OAuth endpoint to be reachable, making that configuration relevant to exposure.
  • System-wide address randomization and non-executable heap and stack protections were enabled, but the main BIG-IP binary was not built as a position-independent executable.
  • SELinux prevented the researchers from directly launching a shell, but they found that modifying the script run after the traffic-management process crashes could still execute a command.
Key Points
  • 01CVE-2026-94127 affects F5 BIG-IP APM OAuth functionality in BIG-IP APM 21.1.0 and selected 17.x releases, while F5 lists hotfixes for the affected branches.
  • 02The patched code rejects Authorization header values larger than 0x4100 bytes before copying them into a heap buffer of the same size.
  • 03On an unpatched system with an OAuth profile configured, sending an Authorization header larger than 0x4100 bytes to an OAuth endpoint caused the target process to crash.
  • 04The researchers reported that a heap object containing a callback function pointer landed after the overflowing buffer in roughly 90% of their test runs, allowing the function pointer to be overwritten.
  • 05Although SELinux blocked an attempted shell launch, the researchers described appending a command to the /etc/bigstart/scripts/tmm.finish crash hook script as a way to run a command after the target process crashed.

Placeholder domain used in dev docs now serves ClickFix attacks
bleepingcomputer.com · 23 Sep 2026 22:46 UTC openai-codex / gpt-5.6-terra

In plain words

A website name often used as a harmless stand-in in developer examples, third-party.com, now shows a fake Cloudflare check to Windows visitors. It tells people to copy and run a command that can download and start unwanted software on their computer. This matters because developers may have copied the name into websites, apps, or test tools, which could lead people or automated software to an attacker-controlled page; unlike example.com, this domain was never protected for safe documentation use.

Summary
The commonly used but unreserved placeholder domain third-party.com is serving a fake Cloudflare verification page that tricks Windows users into pasting and running a malicious PowerShell command. Developers should replace literal references to the domain with IANA-reserved example domains, as copied documentation or test code could direct users to attacker-controlled content.

The domain third-party.com, long used as a placeholder in developer documentation, is serving a fake Cloudflare verification page to Windows users. The page uses a ClickFix scheme: after a visitor clicks its verification box, it copies a PowerShell command to the clipboard and instructs the visitor to open Windows Run, paste the command, and execute it. Manifold Security first reported the behavior after finding references to the domain in public AI skills and MCP server documentation, and BleepingComputer confirmed the fake CAPTCHA page.

The command reconstructs a payload URL, downloads a PowerShell script, and runs it. A May 2026 Hybrid Analysis report showed that the script previously downloaded a 134MB ZIP archive, extracted it, and attempted to launch draw.io.exe, although the archive was unavailable for further analysis and the payload host no longer resolved during testing. The campaign selectively targets Windows users; macOS and Linux visitors instead receive an unsupported-system message.

The incident is notable because third-party.com is not reserved for documentation, unlike IANA-maintained example.com, example.net, and example.org. The domain appears in more than 1,500 files across over 1,700 repositories and is used in some examples that could make real network requests if copied literally. There are no reports that these references have led to ClickFix execution on developers’ devices or in applications, but the live domain could be switched to another active payload source.

  • The malicious page delivers its command-copying behavior only to Windows users, while macOS and Linux visitors receive an unsupported-system message, making a casual review from those systems less likely to reveal the harmful behavior.
  • third-party.com has appeared in more than 1,500 files across over 1,700 repositories, including documentation associated with Chromium, Sanity, and Vercel, despite not being reserved for documentation.
  • Some published examples use third-party.com in code that can make real network requests when copied literally, rather than only displaying it as a written example.
  • The observed payload host was no longer reachable during testing, but third-party.com remained live and could be changed to point to another active payload source.
Key Points
  • 01The domain third-party.com is serving a fake Cloudflare verification page that targets Windows users and attempts to trick them into running a PowerShell command.
  • 02After a visitor clicks the fake verification box, the site copies a command to the Windows clipboard and instructs the user to open Run, paste it, and press Enter.
  • 03The command reconstructs a payload URL, downloads a PowerShell script, and executes it; at the time of testing, the referenced domain no longer resolved.
  • 04A May 2026 Hybrid Analysis report showed the site previously distributed a script that downloaded and extracted a 134MB ZIP archive before attempting to launch draw.io.exe.
  • 05Unlike IANA-reserved example domains, third-party.com is a registered domain that has been widely used as a placeholder in public developer documentation and code examples.
