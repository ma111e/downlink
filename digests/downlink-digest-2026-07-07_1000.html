A 16-year-old Linux kernel vulnerability dubbed Januscape allows attackers to escape a virtual machine and execute arbitrary code on the host. The flaw is tracked as CVE-2026-53359 and was discovered by security researcher Hyunwoo Kim. It stems from a use-after-free weakness in the shadow MMU emulation of KVM/x86, the kernel-based virtual machine for x86 and x86_64 processor architectures.

The vulnerability was patched in June 2026 and was used as a zero-day exploit in Google’s kvmCTF vulnerability reward program. Successful exploitation allows attackers with root access inside a guest virtual machine to execute code as root on the host or crash the host kernel. Kim said the flaw poses a distinct risk to multi-tenant public cloud environments such as Google Cloud and Amazon Web Services because an attacker renting a single instance could affect other virtual machines on the same physical host.

Kim described Januscape as the first guest-to-host exploit that can be triggered on both Intel and AMD processor architectures. On some Linux distributions, such as Red Hat Enterprise Linux, where /dev/kvm is world-writable, unprivileged attackers can also exploit CVE-2026-53359 to reliably gain root permissions on unpatched devices. The researcher published a technical write-up and a proof-of-concept exploit that can trigger a host kernel panic, but said a full guest-to-host escape exploit will not be released for the foreseeable future.
