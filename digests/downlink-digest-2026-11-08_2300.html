In plain words

A harmful version of the @ethersphere/bee-js software package was placed on npm, a service developers use to download code, after someone appears to have misused the project’s release account. Installing version 13.3.0 could download more harmful code that searches for Swarm Desktop wallet files, sends them to an attacker, and sets up a way for the attacker to keep access to the computer. People and organizations that installed this exact version, including through another program that automatically selected it, may be affected. This matters because stolen wallet files and their passwords can let criminals take control of funds, while the added access can endanger the affected computer even after the package is removed.

Summary
@ethersphere/bee-js version 13.3.0 was maliciously published to npm and executes attacker-controlled code during installation to steal Swarm Desktop wallet files and establish persistence on Linux, macOS, and Windows. Do not install it; systems where lifecycle scripts ran should be treated as potentially compromised and investigated beyond simply removing the package.

StepSecurity reported that @ethersphere/bee-js version 13.3.0, published to npm on November 9, 2026, was compromised and executed attacker-controlled JavaScript during installation. The malicious release was introduced through an unsigned direct commit to the project’s upcoming branch under the bee-worker identity, then published through the repository’s legitimate GitHub Actions trusted publishing workflow. Although the npm package had valid SLSA provenance, the malicious code was already present in the repository source used by that workflow.

The package changed its installation scripts to contact api.frameworkmetrics[.]xyz, retrieve JavaScript tailored to Linux, macOS, or Windows, and execute it with the installing user’s permissions. The retrieved code searched for Swarm Desktop wallet configuration and keystore files and sent them to the attacker-controlled server, while platform-specific payloads attempted to establish persistent access through a Linux user service, a macOS LaunchAgent, or a Windows installer sequence. Users should avoid version 13.3.0, check direct and transitive dependency resolutions and installation records, and treat hosts where lifecycle scripts ran as potentially compromised because removing the package alone may not remove persistence.

  • Valid SLSA provenance did not establish that the release was safe because the malicious code was already committed to the legitimate repository before the trusted publishing workflow built and published it.
  • A successful installation log does not show that the payload failed, because the installation hook suppresses network errors after attempting to contact the attacker-controlled server.
  • Projects using version ranges such as ^13.0.0 or ^13.2.0 could resolve to 13.3.0 during a fresh dependency installation or lockfile update, even if their own code was not modified.
  • The malicious behavior runs during installation and does not require anyone to import or use the library, while removing the package afterward may leave installed persistence in place.
  • The reported 3,560 package downloads occurred before the malicious release was published and therefore cannot be used to estimate how many systems installed version 13.3.0.
Key Points
  • 01@ethersphere/bee-js version 13.3.0 was published to npm on November 9, 2026 and runs attacker-controlled JavaScript during installation.
  • 02The malicious package added a post-installation script that contacts api.frameworkmetrics[.]xyz, receives operating-system-specific code, and executes it with the installing user’s permissions.
  • 03Retrieved payloads searched Swarm Desktop directories for config.yaml and swarm.key, then sent their contents to the attacker-controlled server when both files were present.
  • 04The Linux and macOS payloads create persistent user-level services or startup entries, while the Windows payload attempts to install software after adding a Microsoft Defender exclusion.
  • 05Users should avoid version 13.3.0 and treat systems where its installation scripts ran as potentially compromised, because removing the package alone may not remove persistence.

JUSTIFICATION

This is a confirmed malicious npm supply-chain release that executes attacker-controlled code during installation, steals Swarm Desktop wallet material, and attempts persistent access across Linux, macOS, and Windows. Security professionals should urgently identify any direct or transitive installation of @ethersphere/bee-js@13.3.0 and investigate affected hosts.
