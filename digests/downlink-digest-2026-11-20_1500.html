Bitdefender researchers identified a fake website offering a GTA VI streaming client for Windows, despite no official PC version of the game being available at the time. The site instructs visitors to press Win+R, paste a PowerShell command, and run it, a social-engineering technique known as ClickFix.   • The lure avoids the implausible claim of offering a downloadable PC version of GTA VI; instead, it presents itself as a client for streaming the game from a PlayStation or Xbox console.
  • The malicious DLL is designed to forward most functions to a legitimate loadperf.dll, helping the legitimate Windows host program continue operating while one specific function triggers the malicious payload.
  • The final stealer is kept off disk as an embedded executable and injected into legitimate Windows processes, making its activity appear to come from trusted system programs.
  • Simply visiting the lure site without running its command or opening the downloaded file does not complete the installation chain described in the article.
  • The article identifies bypassing PowerShell execution policy and using a command that downloads and immediately executes internet-hosted code as serious warning signs.
