BeyondTrust warned customers to patch two critical security flaws in its Remote Support and Privileged Remote Access software that could allow attackers to bypass authentication. CVE-2026-40138 affects RS and PRA versions 25.3.2 or earlier and stems from improper authentication in the authentication subsystem. CVE-2026-40139 stems from improper processing of BeyondTrust RS authentication requests and can allow unauthenticated remote attackers to gain unauthorized access to vulnerable instances.

BeyondTrust said exploitation of both critical flaws requires a specific authentication configuration to be enabled, but it did not share further details. Shadowserver tracks nearly 2,000 BeyondTrust RS and PRA instances exposed online, though the article says there are no details on how many are honeypots or have already been patched.

In plain words

CERT/CC warned that several Tenda router software versions contain a hidden way to log in as an administrator without the normal password. People using the affected Tenda router models could have their device settings changed by someone who finds and uses this hidden password path. This matters because an attacker could disable protections, reconfigure the router, or take over the device, and no fix was available when the article was written.

Summary
CERT/CC warns that several Tenda router firmware versions contain an undocumented admin backdoor that can bypass normal password checks and grant full web-management control. No patch is available yet, so users should disable remote management and reduce device exposure.

CERT/CC warned that several firmware versions from Chinese network device manufacturer Tenda contain an undocumented authentication backdoor. The issue, tracked as CVE-2026-11405, can allow an attacker to bypass password verification and obtain full administrative control without valid credentials. The affected firmware versions include releases for Tenda FH1201, W15E, AC10, AC5, and AC6 devices.

The backdoor is present in the login() function of the /bin/httpd web server binary. After the normal MD5-based password verification path fails, the code calls GetValue(“sys.rzadmin.password”) to retrieve an alternate password from the device configuration and compares it in plaintext with the submitted password. If the values match, the application grants admin-level access with role=2 and creates a valid elevated session.

CERT/CC said the associated “rzadmin” username is not validated, meaning any username can work when paired with the backdoor password. Successful exploitation can allow unauthorized remote changes to settings, disabling of security features, reconfiguration of the device, and potentially complete device takeover. The vulnerability remained unpatched at the time of writing, and users were advised to disable remote management and change the default LAN IP address.

  • The backdoor path only activates after normal MD5-based authentication fails, which could make it less obvious during routine review of the login process.
  • The backdoor password is compared in plaintext against a device configuration value, rather than being handled through the normal password verification mechanism.
  • Because the username tied to the backdoor is not actually validated, the hidden access does not require knowledge of a specific administrator username.
  • CERT/CC’s recommended mitigations focus on reducing reachability, such as disabling remote management and changing the default LAN IP address, because no patch was available at the time of writing.
Key Points
  • 01CERT/CC warned that several Tenda firmware versions contain an undocumented authentication backdoor that enables administrative access to the devices' web management interfaces.
  • 02The vulnerability is tracked as CVE-2026-11405 and can allow an attacker to bypass password verification and obtain full administrative control without valid credentials.
  • 03The backdoor is present in the login() function of the /bin/httpd web server binary and uses an alternate password value stored as sys.rzadmin.password when normal authentication fails.
  • 04CERT/CC said the associated rzadmin username is not validated, so any username can succeed if paired with the backdoor password.
  • 05The vulnerability remained unpatched at the time of writing, and users were advised to disable remote management and change the default LAN IP address.
