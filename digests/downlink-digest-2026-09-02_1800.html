In plain words

Researchers found a new version of Python NodeStealer, a malicious program that steals sensitive browser and Facebook information, and it now can also record typing, watch copied text, take screenshots, steal Wi-Fi passwords, and take files from a victim’s Pictures folder. It mainly affected victims in Asia and North America, especially in the financial services sector. This matters because the stolen Facebook and personal information can let criminals build a detailed profile of a person, take over accounts, impersonate victims for scams, and sell higher-value stolen data.

Summary
Netskope researchers report that Python NodeStealer has evolved from a Facebook/browser infostealer into full spyware with keylogging, clipboard monitoring, screenshots, Wi-Fi and picture theft, and expanded Facebook Graph API harvesting. The new variant also uses split Telegram C2 channels and shows signs that its added capabilities were AI-assisted.

Netskope Threat Labs has been tracking the Python-based NodeStealer since 2023, and in August 2026 it found a new variant with major upgrades. The malware previously targeted sensitive browser data and Facebook user and Ads Manager accounts, but the latest variant now includes full spyware capabilities. These capabilities include keystroke logging, clipboard monitoring, screenshot capture, and a dual Telegram bot command-and-control architecture.

The latest variant expands its theft targets to include Wi-Fi passwords, the victim’s Pictures folder, and two additional web browsers. Its Facebook targeting also shifts from basic account details to building a broader profile of the person managing the accounts. Netskope reported that the malware now queries more than 20 Facebook Graph API endpoints covering identity, social graph, account security, advertising, and commerce data.

Netskope observed indicators that some newly added capabilities may have been AI-assisted, including decorative emoji labels and identically structured method calls that were absent in older samples. The analyzed malware was also distributed as a compiled .pyc file with nulled header fields, which may mislead researchers about the compilation timeline or disrupt automated decompilation pipelines. The campaign’s victims were mainly in Asia and North America across several segments, led by the financial services sector.

  • The split Telegram bot design means Facebook-specific data and general stolen browser data may continue flowing separately if only one bot token is disrupted.
  • The nulled .pyc header can mislead compilation-timeline analysis and may disrupt automated decompilation, so inspection tools should analyze Python bytecode even when header metadata is abnormal.
  • The expanded Facebook Graph API collection increases the impact from stolen ad account access to identity-level exposure, because it gathers data about the person managing the account as well as business and commerce information.
  • The article identifies decorative emoji use in newly added logging as a distinguishing pattern in the newer code, while noting that this pattern was absent from older NodeStealer samples.
