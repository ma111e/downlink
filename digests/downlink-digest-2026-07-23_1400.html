Summary

The campaign does not exploit a Notepad++ supply-chain compromise, but abuses normal plugin-loading behavior to stealthily install malware.

Ukraine’s CERT uncovered attacks distributing an archive that contains the legitimate Notepad++ application and a malicious utility called LunchPoke disguised as a plugin. The campaign is attributed to UAC-0099, a threat cluster that primarily targets organizations in Ukraine. The group has previously been linked to providing initial access for attacks carried out by APT44, also known as Sandworm.

CERT-UA observed that the attack begins with a ZIP archive containing a VBS script disguised as a PDF document, which retrieves another compressed file named Evernote.zip. That second archive contains Notepad++ version 8.8.3, a malicious plugin named NppExport.dll, a password-protected updater.rar archive, and the legitimate WinRAR executable. The VBS script installs the package into a randomly named directory, launches Notepad++, and loads the malicious DLL through the application’s normal plugin-loading mechanism.

CERT-UA says LunchPoke creates a scheduled task and extracts RemoteLibUpdater.exe and InitTest.dll from the RAR archive. RemoteLibUpdater.exe is BurnyBear, a loader for the MatchBoil V2 malware loader, and BurnyBear also has a fallback mechanism that can trigger RAM and CPU resource exhaustion if launching RemoteLibUpdater.exe fails. CERT-UA did not mention the final payloads, the purpose of the campaign, or the targeted organizations, but advised administrators to update Notepad++, 7-Zip, and WinRAR to reduce exposure to known flaws.

  • The attackers did not need to exploit a Notepad++ vulnerability or compromise its supply chain, because they abused the application's normal plugin-loading mechanism to run the malicious DLL.
  • The attack package includes legitimate software components, including Notepad++ and WinRAR, which can make the activity appear less suspicious while enabling the malware chain.
  • BurnyBear includes a fallback behavior that triggers RAM and CPU resource exhaustion if RemoteLibUpdater.exe fails to launch, adding a disruptive outcome even when the main loading path breaks.
  • CERT-UA mentions CVE-2025-56383 in relation to Notepad++ 8.8.3, but the Notepad++ team disputes the issue and says the behavior is standard plugin functionality.
