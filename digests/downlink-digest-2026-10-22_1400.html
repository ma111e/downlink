SEO Poisoning Campaign Delivers New Armorsteal Malware

In plain words

Researchers found fake websites posing as Chocolatey and Microsoft Activation Scripts that tricked people searching for installation instructions into running harmful commands. The resulting Armorsteal program can give criminals control of a Windows computer, record what the user types, take screenshots, steal saved passwords and browser data, and replace copied cryptocurrency wallet addresses with the criminals’ addresses. This matters because ordinary users looking for legitimate software can be targeted through search results, putting personal accounts, money, and sensitive information at risk.

Summary
Zscaler identified an SEO poisoning campaign using fake Chocolatey and Microsoft Activation Scripts websites to distribute Armorsteal, a Python-based malware suite that provides remote access, keylogging, clipboard wallet hijacking, screenshots, and credential theft. Organizations should hunt for its scheduled tasks and files under C:\Windows\SystemHealth\Update\ and block the identified lure and C2 infrastructure.

In September 2026, Zscaler Threat Hunting identified an SEO poisoning campaign that used fake websites impersonating Chocolatey and Microsoft Activation Scripts (MAS) to distribute Armorsteal. The sites targeted people searching for installation or activation commands and displayed malicious PowerShell commands that downloaded the malware installer. In the Chocolatey lure, the malicious installer also ran the legitimate Chocolatey installer so that the package manager appeared to function normally.

Armorsteal installs a Python 3.11 environment and creates SysCheck2 and SysCheckX scheduled tasks to maintain access through user logon and system boot. Its remote-access component gathers system information, communicates with command-and-control servers, and verifies RSA-2048 signatures before executing received Python tasks. Separate components log keystrokes, monitor and replace copied cryptocurrency wallet addresses, capture screenshots, steal browser and Discord data, collect passwords and SSH keys, and search drives for BIP39 seed phrases. Zscaler recommended investigating the scheduled tasks and files under C:\Windows\SystemHealth\Update\, blocking identified lure and command-and-control domains, and reviewing relevant PowerShell and outbound HTTPS activity.

  • The fake Chocolatey installer also ran the legitimate Chocolatey installer, allowing Chocolatey to appear to work normally while Armorsteal was installed in the background.
  • Armorsteal verifies RSA-2048 signatures on command-and-control tasks and only runs tasks with newer version numbers than those previously executed, limiting execution to authenticated and updated instructions.
  • The remote-access component checks public-IP organization details and exits with a fake “Memory is insufficient” message when it identifies cloud providers such as Google, Amazon, Microsoft, or Azure.
  • During the campaign, the operators changed module downloads from a publicly accessible path to requests requiring a token and matching X-Verify header, while retaining the core malware components.
  • The surveillance component checks copied clipboard content every 0.5 seconds and supports replacing wallet addresses for multiple cryptocurrencies, including Bitcoin, Ethereum, TRON, XRP, TON, and Solana.
Key Points
  • 01Zscaler Threat Hunting identified an SEO poisoning campaign in September 2026 that used fake Chocolatey and Microsoft Activation Scripts websites to distribute the Python-based Armorsteal malware family.
  • 02The malicious installers requested elevated privileges, placed files in C:\Windows\SystemHealth\Update\, and created the SysCheck2 and SysCheckX scheduled tasks to launch Armorsteal at user logon and system boot.
  • 03Armorsteal’s remote access module collects system details, communicates with hardcoded command-and-control domains, and verifies RSA-2048 signatures before executing tasks received from its operators.
  • 04The surveillance module logs keystrokes, monitors and replaces cryptocurrency wallet addresses copied to the clipboard, captures keyword-triggered screenshots, and displays fake wallet transaction notifications.
  • 05The information-stealing module targets Discord tokens, browser cookies and saved passwords, cryptocurrency wallets and BIP39 seed phrases, password-manager data, SSH keys, and Steam session data.
