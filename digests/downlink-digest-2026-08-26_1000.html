In plain words

The article says that in Q2 2026, many more software flaws were reported than before, largely because AI tools are being used both to write software and to find mistakes in it. People using Windows, Linux, Microsoft Exchange, SharePoint, WinRAR, and newer AI tools such as OpenClaw, Dify, and Open WebUI can be affected when these flaws let attackers take over accounts, gain higher access, or change important data. It matters because researchers are sometimes publishing working attack methods before fixes are ready, giving attackers a chance to target unprotected systems more quickly.

Summary
Kaspersky reports that AI-driven development and vulnerability hunting caused CVE volumes and critical flaws to surge in Q2 2026, including new Linux Dirty Frag privilege-escalation bugs and growing vulnerabilities in AI tools themselves. Attackers and APT groups are exploiting newly published and zero-day flaws faster, making rapid patching plus stronger monitoring and access controls essential.

Kaspersky’s Q2 2026 vulnerability and exploit report says the number of registered vulnerabilities reached an unprecedented level, driven primarily by widespread AI use in application development and vulnerability research. The report says AI tools are helping researchers examine large amounts of previously unreviewed code, while AI tools and AI-generated code also introduce security issues of their own. The number of critical vulnerabilities also rose sharply, including new Linux kernel issues tied to the caching subsystem.

The article highlights faster publication and exploitation of flaws, including Windows vulnerabilities for which researchers published technical details or working exploits before CVE identifiers or patches were available. It also describes active exploitation of Linux Dirty Frag-related local privilege escalation vulnerabilities, including issues affecting the Linux networking subsystem and page cache behavior. Older Windows and Linux vulnerabilities, such as Equation Editor, WinRAR, Dirty Pipe, and Netfilter flaws, continued to appear in exploitation telemetry.

The report says APT attacks in Q2 2026 showed a trend toward exploiting new vulnerabilities as soon as they were published, with C2 frameworks such as Sliver, Havoc, AdaptixC2, and Metasploit remaining widely used. It also notes growing vulnerability counts in AI and LLM-related tools, with common issues involving access control, authentication and authorization, and injections. Kaspersky recommends rapid patching, real-time monitoring, stronger access controls, and careful handling of credentials and sensitive data in systems that rely on agents and LLMs.

  • Exploit publication is becoming faster than the traditional disclosure cycle: the article describes Windows exploits released before CVE assignment or patches, which leaves vendors with no time to fix issues before attackers can use the details.
  • AI is affecting vulnerability risk in three separate ways at once: it helps researchers find flaws, introduces flaws in AI tools themselves, and can produce variable-quality code that adds more weaknesses to software.
  • Fake AI-generated vulnerability write-ups for Exchange and SharePoint are being used to waste researchers’ time and, in some cases, to distribute unrelated malware.
  • The article recommends treating AI-agent security as more than a patching problem because agent-based systems may handle credentials, sensitive data, and connected tools with high privileges.
  • For Linux environments, the article gives a concrete mitigation beyond patching: if immediate patching is not possible, organizations should disable vulnerable kernel modules tied to the affected caching-related attack surface.
Key Points
  • 01Kaspersky reports that the number of registered vulnerabilities reached an unprecedented level in Q2 2026, driven primarily by widespread use of AI for application development and vulnerability research.
  • 02The article says researchers increasingly published exploits for unpatched Windows vulnerabilities before CVE identifiers or patches were available, including named issues such as BlueHammer, RedSun, YellowKey, GreenPlasma, RougePlanet, and UnDefend.
  • 03Linux saw disclosure and active exploitation of Dirty Frag-related local privilege escalation vulnerabilities tied to the caching subsystem, including CVE-2026-31431, CVE-2026-43284, CVE-2026-43500, and CVE-2026-46300.
  • 04APT attacks in Q2 2026 showed a trend toward exploiting new vulnerabilities as soon as they were published, and the article highlights Langflow as one of the first cases of an APT group exploiting AI technology.
  • 05Kaspersky found that AI tools accumulated a growing number of registered vulnerabilities in 2025–2026, with common issues involving inadequate access control, improper authentication and authorization, and injections.
