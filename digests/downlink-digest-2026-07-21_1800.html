His team now recommends a 7-day cooldown period before adopting new package versions and held workshops to explain this change to engineering teams. Singh also emphasizes tools that fit developer workflows, including in-IDE vulnerability detection and device protection that can block malicious packages, browser extensions, and IDE plugins at install time without harming productivity.

  • A technically valid security control can create long-term resistance if it blocks a small but critical developer group, as Singh’s local administrator rights rollout damaged trust for a year despite working for most users.
  • Security guidance may need to reverse or qualify earlier advice when attackers adapt, as Tyro now tells developers to delay new package versions after years of encouraging fast dependency updates.
  • Developer trust functions like a limited resource for security teams, because a poorly handled rollout can make later nuanced requests such as “patch, but wait a week” harder to enforce.
  • Singh’s preferred controls reduce the need for developer behavior changes by acting inside existing workflows, such as scanning in the IDE or blocking unsafe installs at install time while allowing safe ones through silently.
Key Points
  • 01Arun Singh says that being highly skilled in cybersecurity is not enough if a security leader cannot influence the business and earn developer trust.
  • 02Singh’s earlier removal of local administrator rights across all workstations disrupted software engineers’ productivity and took about a year of trust-building to recover from.
  • 03Tyro’s recent board conversations have focused on supply chain attacks, where attackers can exploit the long-standing advice for developers to keep packages and dependencies up to date.
  • 04Singh’s team now advocates a 7-day cooldown period before adopting any new package version, and they held workshops with engineering teams to explain the reasoning.
  • 05Singh says security tools should fit developer workflows, including in-IDE vulnerability detection and device protection that can block malicious packages, browser extensions, and IDE plugins at install time.
