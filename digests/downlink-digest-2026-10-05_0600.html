In plain words

Citrix released fixes for a serious flaw in its NetScaler products after targeted attacks used it to take affected systems offline. The issue affects organizations that run their own NetScaler systems and use them for SAML, a common way to let people sign in using another service. Repeated abuse can keep these services unavailable, disrupting access for users, although Citrix says it has not found evidence that customer data was changed. U.S. federal agencies have been directed to apply the updates by October 7, 2026.

Summary
Citrix patched CVE-2026-88779, an actively exploited high-severity memory overflow in NetScaler ADC and Gateway SAML deployments that can cause persistent denial of service. Organizations using NetScaler as a SAML service or identity provider should update to the fixed releases immediately.

Citrix released security updates for CVE-2026-88779, a high-severity memory overflow vulnerability in NetScaler ADC and NetScaler Gateway with a CVSS score of 8.7. Citrix said the flaw has been exploited in targeted zero-day attacks against unmitigated customer-managed deployments. The company said successful exploitation can cause denial of service and, if repeatedly triggered, may leave the service unavailable.

The vulnerability applies when NetScaler is configured as a SAML service provider or SAML identity provider, which organizations can check through specific SAML configuration entries. Citrix said it has not identified an impact on customer-data integrity, indicating its analysis found the issue affects service availability. Fixed versions are available for supported NetScaler 14.1, 13.1, FIPS, and NDcPP releases, and CISA added the flaw to its Known Exploited Vulnerabilities catalog with an October 7, 2026 patch deadline for U.S. federal agencies.

  • Organizations can quickly determine whether they meet the affected configuration condition by checking for "add authentication samlAction" entries for SAML service provider use or "add authentication samlIdPProfile" entries for SAML identity provider use.
  • The flaw is limited to service availability rather than identified customer-data integrity impact, but repeated triggering can keep the affected service offline.
  • watchTowr said it reproduced the flaw within hours after observing activity against NetScaler honeypots, while Citrix confirmed targeted exploitation of unpatched deployments.
  • The advisory follows active exploitation of two other NetScaler flaws, CVE-2026-88771 and CVE-2026-88772, which attackers have used to install web shells and tunneling tools.
Key Points

  • 02Citrix said the flaw has been used in targeted attacks against unpatched NetScaler deployments and can cause denial of service, potentially leaving a service unavailable if repeatedly triggered.
  • 03The issue affects customer-managed NetScaler deployments configured as either a SAML service provider or a SAML identity provider.
  • 04Citrix said it has not identified an impact on the integrity of customer data from CVE-2026-88779.
  • 05CISA added CVE-2026-88779 to its Known Exploited Vulnerabilities catalog and required U.S. federal agencies to apply patches by October 7, 2026.

Attackers Target Rejetto HFS Flaw That Enables Admin Session Forgery and RCE
thehackernews.com · 05 Oct 2026 08:09 UTC openai-codex / gpt-5.6-terra

In plain words

A serious flaw in Rejetto HTTP File Server lets outsiders trick affected servers into treating them as administrators, giving them control and the ability to run commands. Attempts to use the flaw have already targeted vulnerable systems in the United States from an unnamed actor in China. People and organizations using HFS versions 3.0.0 through 3.2.0 are affected, and the risk is serious because attackers can take over the server and use it for harmful activity.

Summary
Attackers are actively exploiting CVE-2026-61500 in Rejetto HTTP File Server versions 3.0.0–3.2.0 to forge administrator sessions and achieve remote code execution. Organizations should upgrade to HFS 3.2.1 or later immediately.

A critical flaw in Rejetto HTTP File Server (HFS), tracked as CVE-2026-61500 and rated 9.3, is facing active exploitation attempts, according to VulnCheck. The issue affects HFS versions 3.0.0 through 3.2.0 and can allow remote attackers to forge an administrator session and take control of affected systems. VulnCheck detected attempts on October 1, 2026, including activity from an unnamed China-based threat actor targeting vulnerable hosts in the United States.

The flaw stems from HFS generating its session-cookie signing key with the non-cryptographic JavaScript Math.random() function while exposing outputs from the same generator during unauthenticated login. An attacker can gather a small number of login responses, reconstruct the generator’s state, recover the signing key, and create a valid administrator cookie. With administrator access, the documented server_code configuration feature can be used to execute server-side JavaScript and achieve remote code execution.

Rejetto released a patch in HFS version 3.2.1 in July 2026, while a Python proof-of-concept exploit became public in late September. Horizon3.ai researcher Zach Hanley said Anthropic’s Mythos model was used to discover the vulnerability. This is the second Rejetto HFS flaw known to be actively exploited, following CVE-2024-23692, which was used in 2024 to distribute cryptocurrency miners, trojans, and HATVIBE malware.

  • The issue is not limited to guessing a password: exposed login data can be used to recreate the server’s random-number state and produce a valid administrator session cookie.
  • HFS’s documented server_code configuration feature turns the session-forgery flaw into full remote code execution once an attacker gains administrator access.
  • Exploitation was detected shortly after public technical details and a Python proof-of-concept became available, highlighting the short window between public disclosure and real-world targeting.
  • Rejetto HFS has now had two high-severity flaws observed under active exploitation, following CVE-2024-23692 in 2024.
Key Points
  • 01CVE-2026-61500 is a critical flaw in Rejetto HTTP File Server versions 3.0.0 through 3.2.0 that allows administrator session forgery and remote code execution.
  • 02The flaw results from HFS using the non-cryptographic Math.random() generator for its session-cookie signing key while exposing outputs from the same generator during unauthenticated login.
  • 03A remote attacker can collect login responses, reconstruct the generator state, recover the signing key, and forge an administrator session cookie.
  • 04Rejetto released a fix in HFS version 3.2.1 in July 2026, and a public Python proof-of-concept exploit was released in late September 2026.
  • 05VulnCheck detected exploitation attempts on October 1, 2026, including an unnamed China-based threat actor targeting vulnerable hosts in the United States.

In plain words

Google has temporarily stopped accepting many bug reports about security problems in the open-source software it maintains because it received a large number of automated, mostly invalid reports created with AI. Security researchers can still report supply-chain issues, submit fixes through another Google program, and report problems affecting Google Cloud products. The pause shows that AI-generated noise can overwhelm programs meant to find real software flaws, making it harder and more costly to sort genuine reports from false ones.

Summary
Google has temporarily halted product-vulnerability submissions to its Open Source Software Vulnerability Rewards Program after a surge of mostly invalid AI-generated reports. Supply-chain reports and existing submissions remain unaffected while Google redesigns the program, with an update expected in Q1 2027.

Google has temporarily stopped accepting product-vulnerability submissions through its Open Source Software Vulnerability Rewards Program (OSS VRP) after a significant increase in automated reports, most of which it says are invalid. The program covers Google-maintained open-source projects including Golang, Angular, Bazel, Protocol Buffers, and Fuchsia, as well as some third-party dependencies and repository configurations. Google said the pause does not affect supply-chain reports or outstanding reports, including product-vulnerability reports submitted before October 1, 2026.

Researchers can still submit high-impact open-source fixes through Google’s Patch Rewards Program, which offers rewards up to $15,000, and can report qualifying issues in Google Cloud open-source repositories through the Cloud VRP. Google is revising the OSS VRP to address the automated-submission problem and expects to provide an update in Q1 2027. The article notes similar pressure elsewhere: curl ended its HackerOne bug bounty program after AI-generated reports overwhelmed maintainers, while Microsoft has warned that AI-assisted vulnerability discovery raises operational demands across the software industry.

  • Google’s pause is limited to OSS VRP product-vulnerability submissions: supply-chain reports, previously submitted reports, Patch Rewards submissions, and qualifying Google Cloud open-source reports remain available paths for researchers.
  • The program redesign is expected to take months, as Google committed only to an update in Q1 2027 after stopping affected submissions in October 2026.
  • The issue is not isolated to Google: curl ended its HackerOne bounty program after AI-generated report volume, and Intel removed financial rewards from its Intigriti program.
  • Google paid a record $17.1 million to more than 700 researchers in 2025, illustrating that the automated-report problem is affecting a large, active vulnerability-reporting ecosystem.
  • Microsoft warned that AI-assisted discovery is increasing the volume of identified software flaws and the operational effort needed to handle them.
Key Points
  • 01Google temporarily suspended product-vulnerability submissions to its Open Source Software Vulnerability Rewards Program because of a significant increase in automated reports, most of which were invalid.
  • 02The suspension does not affect supply-chain reports or reports submitted before October 1, 2026.
  • 03Researchers can still submit open-source security patches through Google’s Patch Rewards Program and report Google Cloud open-source repository issues affecting Cloud products through the Cloud VRP.
  • 04Google said it is redesigning the OSS VRP to address automated submissions and plans to provide an update in Q1 2027.
  • 05Curl ended its HackerOne bug bounty program in January after a flood of AI-generated reports, while Intel removed financial rewards from its Intigriti program in mid-September.

Summary
Microsoft confirmed that the optional Windows 11 KB5124010 preview update can cause some games and applications using built-in AC-3 (Dolby Digital) audio decoding to crash or close unexpectedly. The company is working on a fix; affected users can avoid installing the update for now.

Microsoft confirmed that the September 2026 KB5124010 Windows 11 preview update can cause some games and applications using AC-3, also known as Dolby Digital, audio decoding to crash.
