In plain words

7-Zip released version 26.02 to fix a flaw that could let criminals run harmful code on someone’s computer if they tricked that person into opening a specially made compressed file. This affects people using 7-Zip, especially on Windows, and they need to download the new version themselves because the program does not update automatically. It matters because 7-Zip is widely used, and similar file-opening tricks have been used before in phishing and social engineering campaigns to install malware.

Summary
7-Zip 26.02 fixes a remote code execution flaw in its XZ decompression handling that could be triggered by a malicious archive. Because 7-Zip does not auto-update, users should manually install the latest version from the official site.

7-Zip version 26.02 was released to fix a remote code execution vulnerability that could allow attackers to execute malicious code if users open specially crafted compressed files. The flaw was disclosed by Lunbun researcher Landon Peng and exists in 7-Zip’s processing of XZ-compressed data. According to a Zero Day Initiative advisory, specially crafted XZ data can trigger a heap-based buffer overflow and potentially allow arbitrary code execution as the user.

The developer has not published technical details about the flaw, but the 26.02 source code changes suggest it is related to how 7-Zip tracks available space while decompressing XZ data. The patch adds checks to ensure the decoder cannot write beyond the remaining available space in an output buffer. The advisory says exploitation requires user interaction, such as visiting a malicious page or opening a malicious archive file.

7-Zip does not include an automatic update feature, so users must manually download the latest version from 7-zip.org to receive the fix. The article notes that 7-Zip is widely used on Windows and that flaws in archive utilities can be attractive to threat actors. There are currently no reports that attackers are actively exploiting this newly disclosed vulnerability, but users are advised to update to version 26.02 as soon as possible.

  • The lack of an automatic update feature makes this fix especially actionable because vulnerable users will remain exposed unless they manually install 7-Zip 26.02 from the official site.
  • Although the developer has not published technical details, the source code changes indicate the fix centers on preventing the XZ decoder from writing past the remaining output buffer space.
  • The article highlights archive-file flaws as a practical threat because attackers have previously exploited 7-Zip and WinRAR vulnerabilities through phishing or social engineering campaigns.
  • The absence of current exploitation reports does not remove the risk, since 7-Zip’s widespread Windows usage makes its archive-handling flaws attractive targets for future attacks.
