In plain words

Microsoft released fixes for 1,413 security problems in Windows, Office, SharePoint, SQL Server, and other software, including one Windows problem that criminals are already using. That flaw can let a harmful file sent through email or a message get around Windows warnings if a person is persuaded to open or click it. Businesses, government agencies, and anyone using affected Microsoft software should install the updates, because some problems could let attackers run unauthorized programs, view sensitive information, or disrupt systems.

Summary
Microsoft released patches for a record 1,413 vulnerabilities, including CVE-2026-96951, a Windows Shell flaw actively exploited to bypass Mark of the Web protections. Organizations should prioritize the exploited Windows Shell bug and publicly disclosed .NET WDAC bypass, then use Microsoft's risk cohorts to triage the broader update set.

Microsoft released patches for a record 1,413 vulnerabilities across Windows, Office, Developer Tools, SharePoint Server, SQL Server, and other products. More than 670 of the flaws involve privilege escalation, over 300 involve remote code execution, and more than 70 are rated Critical. The release includes an actively exploited Windows Shell command injection vulnerability, CVE-2026-96951, which has a CVSS score of 8.8.

Microsoft said CVE-2026-96951 can allow an attacker to evade Mark of the Web protections through a specially crafted file, although the attacker must convince a user to click a link or interact with a malicious attachment. CISA added the flaw to its Known Exploited Vulnerabilities catalog and directed U.S. federal agencies to apply fixes by October 16, 2026. Other notable fixes include the publicly known CVE-2026-108398 .NET Framework flaw, which can bypass Windows Defender Application Control, and CVE-2026-21413 in Raw Image Extension, which can be triggered when Windows previews a crafted RAW image file. Microsoft also introduced risk cohorts to help organizations group related CVEs for prioritization while assessing exploitation status, severity, attack path, user interaction, and product-specific guidance.

  • The update volume is exceptionally high, but the article emphasizes that organizations should prioritize flaws with active exploitation, public disclosure, and relevant attack conditions rather than treating every CVE equally.
  • The actively exploited Windows Shell issue requires an attacker to persuade a user to interact with a crafted file or link, showing that email and instant-message delivery remain relevant despite the technical flaw being in Windows.
  • The .NET Framework issue is especially significant after an attacker already has local access because it can bypass Windows Defender Application Control without requiring user interaction.
  • The Raw Image Extension flaw can be triggered when Windows creates a thumbnail or preview of a crafted RAW image, meaning the user does not need to open the image file for the issue to occur.
  • Microsoft's new risk cohorts are intended to group CVEs that need similar customer assessment, while still requiring organizations to review each flaw's exploitation status, severity, attack path, user interaction requirements, and affected product guidance.
Key Points
  • 01Microsoft released patches for 1,413 vulnerabilities, including 1,102 in Windows, 134 in Office, 36 in SharePoint Server, and 22 in SQL Server.
  • 02CVE-2026-96951 is a Windows Shell command injection flaw with a CVSS score of 8.8 that Microsoft said has been actively exploited to evade Mark of the Web protections.
  • 03CISA added CVE-2026-96951 to its Known Exploited Vulnerabilities catalog and required U.S. federal agencies to apply fixes by October 16, 2026.
  • 04Microsoft said the publicly known CVE-2026-108398 flaw in .NET Framework could allow an authenticated local attacker to bypass Windows Defender Application Control and execute code in a protected process.
  • 05Microsoft also patched CVE-2026-21413, a CVSS 9.8 heap-based buffer overflow in Raw Image Extension that can enable remote code execution when Windows generates a thumbnail or preview of a crafted RAW image file.
