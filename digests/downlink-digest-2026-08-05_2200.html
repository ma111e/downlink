Shai-Hulud strikes again: CHAINDROP worm hits 400+ npm packages
elastic.co · 06 Aug 2026 00:00 UTC openai-codex / gpt-5.5
TAGSbunchaindropclaude-codeelastic-security-labsethereum-smart-contractgithubkeyvmath-symbol-jsnpmsetup-mjsshai-huludvisual-studio-code

In plain words

Elastic Security Labs found that attackers backdoored the widely used keyv software project and used a self-spreading program called CHAINDROP to compromise more than 400 npm packages. This matters because keyv alone was downloaded over 600 million times last month, and related packages were also downloaded by millions of developers and software projects. The malicious code can run when someone installs an affected package or even opens an infected repository in tools like Claude Code or VS Code, then steal account keys and use them to spread to more packages. Anyone using the affected packages or working from impacted developer machines may need to revoke and replace credentials for services like GitHub, npm, cloud platforms, Kubernetes, Vault, AI tools, and CI/CD systems.

Summary
Elastic Security Labs found a new Shai-Hulud npm supply-chain campaign in which the CHAINDROP worm compromised 400+ packages, including the widely used keyv ecosystem, by stealing developer credentials and using npm tokens to automatically backdoor more packages. Affected teams should avoid immediate package updates, hunt for the listed indicators, and rotate npm, GitHub, cloud, CI/CD, and other secrets from impacted systems.

Elastic Security Labs identified a new Shai-Hulud campaign on August 4, 2026, targeting the maintainer of keyv, a widely used key-value storage library. The attackers trojanized the monorepo and embedded a self-propagating worm called CHAINDROP that uses stolen npm credentials to backdoor other packages the maintainer can publish. At the time of writing, more than 400 unique npm packages had been compromised, with keyv alone receiving over 600 million downloads in the previous month.

CHAINDROP is triggered through a preinstall hook in package.json, which runs commands before a package is installed. The malware uses a dropper called setup.mjs to download and run bun if needed, then execute an obfuscated payload named Math_Symbol.js or math_init.js across Linux, macOS, and Windows. The payload harvests credentials from more than 300 patterns, including AI tooling, cloud providers, GitHub, HashiCorp Vault, SSH private keys, Kubernetes service account tokens, and npm tokens.

The worm retrieves its exfiltration endpoint from an Ethereum smart contract and can fall back to GitHub commit history or public GitHub repositories if other paths fail. When it finds an npm token with package write permissions and the ability to publish without two-factor authentication, it downloads writable packages, injects malicious components, patches package.json, bumps the patch version, and republishes them. The article recommends delaying adoption of new package updates, revoking affected GitHub and npm tokens, checking repositories for unauthorized chore: update config commits, rotating impacted credentials, upgrading to npm 12 or later, and enabling 2FA on npm accounts.

  • The filename can help distinguish the infection path: Math_Symbol.js appears in packages compromised directly from the keyv monorepo, while math_init.js appears in packages trojanized during worm propagation, even though both files share the same SHA-256 hash.
  • Developers can be infected without installing a package because the campaign also abuses Claude Code SessionStart hooks and VS Code folderOpen tasks to execute setup.mjs when an infected repository is opened.
  • The worm only propagates through npm tokens that both have package write permissions and can publish without two-factor authentication, making revocation of bypass_2fa automation tokens especially urgent.
  • Worm-generated GitHub commits have recognizable markers, including the author name claude and the commit message chore: update config, which gives defenders a concrete way to search repositories for unauthorized changes.
  • CHAINDROP’s use of an Ethereum smart contract to retrieve its exfiltration endpoint lets the attacker rotate infrastructure without modifying the payload, so blocking only the domains observed during detonation may be insufficient.
Key Points
  • 01Elastic Security Labs identified a new Shai-Hulud campaign on August 4, 2026, targeting the maintainer of keyv and compromising more than 400 unique npm packages.
  • 02CHAINDROP executes through a preinstall hook in package.json and uses a dropper called setup.mjs to run an obfuscated payload named Math_Symbol.js or math_init.js across Linux, macOS, and Windows.
  • 03The payload includes a credential harvester that scans more than 300 patterns for credentials related to AI tools, cloud providers, GitHub, HashiCorp Vault, SSH keys, Kubernetes service account tokens, and npm tokens.
  • 04CHAINDROP retrieves its exfiltration endpoint from an Ethereum smart contract and can fall back to GitHub commit history or public GitHub repositories for exfiltration if other methods fail.
  • 05When CHAINDROP finds an npm token with package write permissions and the ability to publish without two-factor authentication, it downloads writable packages, injects malicious components, patches package.json, bumps the patch version, and republishes them to npm.

In plain words

Maksim Silnikau, a Belarusian man who created and ran the Ransom Cartel operation, was sentenced to 16 years in U.S. prison for helping criminals break into companies, lock their computers, steal data, and demand money. At least 18 companies worldwide were attacked, including organizations in California, New York, Nebraska, and outside the United States, with known losses of more than $6.7 million. The real-world impact included a medical technology startup being disrupted for two months and law firms being unable to operate normally for weeks or months, showing how these crimes can stop businesses and services from functioning.

Summary
Maksim Silnikau, the Belarusian creator and administrator of the Ransom Cartel ransomware operation, was sentenced to 16 years in U.S. prison for attacks on at least 18 organizations worldwide. Prosecutors said the group attempted to extort at least $5.2 million and caused more than $6.7 million in known victim losses.

Maksim Silnikau, a 40-year-old Belarusian national, was sentenced to 16 years in prison for his role as the creator and administrator of the Ransom Cartel ransomware operation. The U.S. Department of Justice said he was sentenced for conspiracy to commit offenses against the United States, conspiracy to commit wire fraud, and aggravated identity theft. Prosecutors said Ransom Cartel affiliates attacked at least 18 companies worldwide between 2021 and 2023 and attempted to extort at least $5.2 million from victims.

According to court documents, Silnikau began developing Ransom Cartel in May 2021 and recruited other cybercriminals through underground forums. He supplied members with stolen credentials and software used to encrypt victims’ computers, and he operated an affiliate website used to manage attacks, communicate, negotiate ransom demands, and distribute revenue shares. The operation stole corporate data and demanded payment for decryption keys or promises not to leak stolen information.

The United States identified more than \(6.7 million in losses among 18 known victims, with prosecutors saying the total was likely higher because some victims had not reported attacks. Reported incidents included a medical technology startup disrupted for two months and law firm infrastructure outages lasting from several days to multiple months, with two law firms paying ransoms of \)125,000 and $300,000. Silnikau was initially arrested in Spain in July 2023, fled while awaiting extradition, was later captured while trying to return to Belarus, and was ultimately extradited from Poland to the United States.

  • Ransom Cartel’s impact extended beyond ransom demands, with one medical technology startup disrupted for two months and law firm infrastructure outages lasting from several days to multiple months.
  • Researchers linked Ransom Cartel to REvil through shared code similarities, but missing REvil obfuscation features suggested it may have been built by someone without access to the full REvil source code.
  • Silnikau’s role covered multiple parts of the operation, including recruiting affiliates, coordinating with initial access brokers, communicating with victims, handling ransom payments, and using cryptocurrency mixers to obscure funds.
  • The known financial harm was likely incomplete because prosecutors said some victims had not reported their attacks, even though 18 identified victims already accounted for more than $6.7 million in losses.

  • 03According to court documents, Silnikau began developing Ransom Cartel in May 2021, recruited other cybercriminals through underground forums, supplied tools and stolen credentials, and operated an affiliate website for managing attacks and ransom payments.
  • 04Federal prosecutors said Ransom Cartel affiliates attempted to extort at least $5.2 million and caused more than $6.7 million in known losses among 18 victims.
