A malicious browser extension named Twitch Enhanced Viewer | JeetBot leaked Twitch OAuth tokens associated with nearly 31,000 users across Chrome and Firefox. The extension was listed on the Chrome Web Store with about 30,000 users and on Firefox Add-Ons with 604 users. It presented itself as a tool for improved Twitch viewing, including 1080p streams in restricted regions and an ad-free experience.

According to Socket researcher Kush Pandya, current v85.x builds routed Twitch video-playlist requests through operator-controlled proxy servers and included users’ tokens in an auth URL parameter. This caused the tokens to be written in cleartext to proxy request logs, although a hard-coded list of 10 Twitch channels was exempt from forwarding. A holder of a live Twitch OAuth session token can act on an account without the password or second factor, including reading and sending whispers, posting chat messages, and spending channel points.

JeetBot’s documentation says Firefox version 85.8.7 changes the playlist process so that OAuth tokens are no longer sent to its proxies, while an equivalent Chrome release was under review. Users with older versions were told to update or temporarily disable the extension to stop further transmission. The developer also warned that disabling or updating it does not revoke tokens that had already been sent.

  • The extension’s token forwarding was selectively disabled for 10 hard-coded channels, while viewers of other channels had their live session tokens sent through the operator’s proxy infrastructure.
  • Sending tokens in a URL parameter meant they could be stored in the proxy servers’ request logs as readable text rather than only being used temporarily to retrieve video playlists.
  • Users cannot eliminate the risk from tokens already sent merely by disabling or updating the extension, because the developer states that prior transmissions are not revoked.
  • The Chrome and Firefox store descriptions did not disclose that the extension routed authenticated Twitch sessions through operator-controlled servers, despite its broad Twitch host permissions.
  • Earlier version 4.x builds reportedly sent tokens directly to a dedicated set-token endpoint and used deno.dev and deno.net as backup destinations.
Key Points
  • 01The Twitch Enhanced Viewer | JeetBot extension on the Chrome Web Store and Firefox Add-Ons store exposed OAuth tokens associated with nearly 31,000 users by forwarding them to operator-controlled proxy servers.
  • 02The extension sent users' Twitch tokens as an auth query parameter when routing video-playlist requests through its proxy infrastructure, causing the tokens to be recorded in proxy request logs in cleartext.
  • 03A Twitch OAuth session token can allow its holder to act on an account without its password or second factor, including reading and sending whispers, posting in chat, and spending channel points.
  • 04The token-forwarding behavior excluded a hard-coded list of 10 Twitch channels, most of which are Russian-language streamers.
  • 05JeetBot's documentation says Firefox extension version 85.8.7 no longer sends users' Twitch OAuth tokens to its proxies, but tokens transmitted by older versions are not revoked by updating or disabling the extension.
