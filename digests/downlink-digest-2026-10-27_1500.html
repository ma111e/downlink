In plain words

Censys has added an interface that lets security teams automatically investigate suspicious internet addresses, website names, or threat reports from their existing tools. It can find related websites and servers that may be run by the same criminal operation, helping companies block them and search their records for signs that employees or systems contacted them. This matters because attackers often use many changing addresses, so finding the wider group can help teams detect and contain an incident before more systems are affected.

Summary
Censys has launched an API for its Investigator agentic framework, enabling scripts, SOAR playbooks, and AI agents to expand known indicators into related infrastructure, detection artifacts, and monitorable CenQL queries. The service is positioned for automated CTI enrichment, SOC triage, and incident response scoping.

Censys announced an API for Censys Investigator, its agentic investigation framework. The API lets scripts, SOAR playbooks, and AI agents submit domains, IP addresses, or full threat-intelligence reports as inputs. It returns a downloadable report identifying related infrastructure, such as IPs, domains, services with shared fingerprints, and a CenQL query for the resulting cluster.

Censys positions the API for threat-intelligence enrichment, escalated SOC triage, and incident response investigations. In an example using a Microsoft report on phishing that abused MSP360 RMM to install ScreenConnect, Censys says seven published domains expanded into a 69-asset cluster, including previously unlisted domains. The article also describes using time-bounded searches to focus on infrastructure active during an incident and converting cluster queries into Collections for ongoing monitoring. Investigations do not use Censys Credits, but organizations are limited to 150 per week, users can run three concurrently, and results are retained for seven days.

  • The article emphasizes that infrastructure attributes such as banner hashes and a ScreenConnect extension UUID can remain useful longer than domains because changing them may require rebuilding an attacker’s deployment.
  • In the Microsoft phishing example, only three of seven initial indicators were useful for pivoting, while two led to 58 additional ScreenConnect hosts and websites through matching banner hashes.
  • Time-bounding an investigation to the period when suspicious communications occurred can focus results on infrastructure used during an incident rather than its current state.
  • Turning an investigation’s CenQL query into a Collection and attaching a webhook can continuously surface newly deployed infrastructure associated with the same operator.
Key Points
  • 01Censys Investigator now has an API that accepts domains, IP addresses, and full threat-intelligence reports from scripts, SOAR playbooks, and AI agents.
  • 02Each investigation returns a downloadable report of related infrastructure, including IPs, domains, services sharing fingerprints, and a CenQL query intended to match the identified cluster.
  • 03Censys describes use cases for the API in threat-intelligence enrichment, escalated SOC alert triage, and digital forensics and incident response.
  • 04In an example based on a Microsoft phishing report, Censys Investigator expanded seven listed domains into a 69-asset cluster and identified additional domains not included in Microsoft’s list.
  • 05Investigations do not consume Censys Credits, but each user may run three concurrently, organizations are limited to 150 per week, and results are retained for seven days.
