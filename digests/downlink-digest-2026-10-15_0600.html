In plain words

Attackers are trying to use a serious flaw in Langflow, a tool for building AI applications, to take control of computers running older versions of the software. The flaw requires logging in first, but researchers saw attackers trying common usernames and passwords and then using the access to run commands, steal secret settings, and potentially reach other systems. This matters because a successful break-in could give attackers lasting control of a server and expose sensitive information; Langflow users should update to version 1.9.0 or later and limit access to trusted users.

Summary
Attackers are actively targeting CVE-2026-105740, a critical authenticated RCE flaw in Langflow versions before 1.9.0 that lets any authenticated user execute arbitrary server commands through malicious MCP server configurations. Organizations should upgrade immediately, disable auto-login, enforce strong credentials, and investigate suspicious requests to Langflow MCP endpoints.

Threat actors are actively exploiting CVE-2026-105740, a critical Langflow flaw with a CVSS score of 9.9 that affects versions before 1.9.0. Langflow is an open-source platform for building AI applications and agentic workflows. Previdian recorded 1,423 exploit attempts against its honeypot sensors from 27 unique IP addresses since September 19, 2026. Activity increased sharply on October 11, when 333 attempts were observed.

The flaw allows any authenticated Langflow user, including a non-admin user, to execute arbitrary operating-system commands by adding an MCP server using the stdio transport. Langflow passes the user-provided command directly to a shell without validation, and fetching the MCP server list triggers the command. Attackers can also inject environment variables, while malicious server configurations persist and re-execute whenever the server list is loaded. Observed payloads sought Langflow secrets and environment variables, attempted Docker-based access to the host filesystem, and ran commands such as id and whoami.

In one observed sequence, attackers checked the Langflow version, attempted the auto-login endpoint, authenticated with common credentials, and used the resulting bearer token to reach the vulnerable endpoint. Langflow users are advised to upgrade to a patched version, disable auto-login, use strong unique passwords, limit accounts to trusted users, and review authentication logs and requests to /api/v2/mcp/servers/ for suspicious activity. If patching cannot happen immediately, Langflow should not be exposed directly to untrusted networks and LANGFLOW_AUTO_LOGIN should be set to false.

  • The malicious MCP server configuration can provide persistence because its command is executed again whenever the server list is loaded.
  • MCP server configurations are stored in project settings and are not visible during normal flow review, making malicious entries easier to miss than custom component code.
  • In an observed honeypot sequence, attackers first checked the Langflow version, tried the disabled auto-login endpoint, then successfully used common credentials to obtain a bearer token and access the vulnerable endpoint.
  • The issue permits not only command execution but also environment-variable injection, including potentially changing the command search path or loading attacker-controlled code through LD_PRELOAD.
  • Observed payloads included Docker commands intended to access the underlying host filesystem, showing that attackers were probing beyond the Langflow application itself.
Key Points
  • 01CVE-2026-105740 is a critical authenticated remote-code-execution flaw, rated 9.9 out of 10, affecting Langflow versions before 1.9.0.
  • 02The flaw allows any authenticated Langflow user, including a non-administrator, to run arbitrary operating-system commands by creating an MCP server configuration with the stdio transport and then fetching the server list.
  • 03Previdian recorded 1,423 exploit attempts from 27 attacker IP addresses against its honeypot sensors since September 19, 2026, with activity rising to 333 attempts on October 11.
  • 04Observed payloads attempted to collect Langflow environment variables and secret settings, access the host filesystem through Docker commands, and run basic commands such as id and whoami.
  • 05Langflow and Previdian recommend upgrading to a patched version, disabling auto-login, using strong unique passwords, restricting access to trusted users, and reviewing requests to the MCP server endpoints.

Summary

Palo Alto Networks released security updates for CVE-2026-0322, a high-severity remote code execution flaw in the PAN-OS management interface that it says is under active, though very limited, exploitation. An authenticated attacker with network access can use the issue to execute arbitrary code with root privileges on an affected firewall. Palo Alto Networks said no special configuration is required for exploitation.

The flaw affects PAN-OS on PA-Series and VM-Series firewalls and Panorama virtual and M-Series systems; Cloud NGFW and Prisma Access are not affected. The company provided fixed PAN-OS releases across supported version branches and recommended limiting management-interface access to trusted internal IP addresses or a jump box. CISA added CVE-2026-0322 to its Known Exploited Vulnerabilities catalog, along with Cisco Secure Email Gateway flaw CVE-2026-76519. Federal Civilian Executive Branch agencies are required to prioritize fixes for both issues by October 17, 2026. Cisco said CVE-2026-76519 is being exploited and could allow an unauthenticated remote attacker to write arbitrary files and execute commands with root privileges when the file reputation service is enabled.

  • Although exploitation requires authenticated access, the flaw can grant root-level control of the firewall and does not require any special configuration to be exploitable.

  • Palo Alto Networks described observed exploitation as "very limited" but publicly identified three U.S.-geolocated IP addresses assessed to be associated with the attempts.
  • CISA added the issue to its Known Exploited Vulnerabilities catalog and directed Federal Civilian Executive Branch agencies to prioritize remediation by October 17, 2026.
