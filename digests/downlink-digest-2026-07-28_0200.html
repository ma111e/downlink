Attackers Exploit Arista VeloCloud Orchestrator Command Injection Flaw
thehackernews.com · 28 Jul 2026 04:43 UTC openai-codex / gpt-5.5
TAGSalibabaaristacisacommand-injectioncve-2025-68686cve-2026-16723cve-2026-16812fastjsonfortinetfortios-ssl-vpnknown-exploited-vulnerabilities-catalogremote-code-executionunited-statesvelocloud-orchestrator

In plain words

Attackers are already abusing a serious flaw in on-premises versions of Arista VeloCloud Orchestrator, a system used to manage VeloCloud network devices. Organizations running affected versions could have their orchestrator and the data it manages taken over or changed, and attackers may also reach the VeloCloud Edge devices connected to it. Arista has released fixed versions and shared three attacking IP addresses, while CISA has ordered U.S. federal civilian agencies to patch by July 30, 2026.

Summary
A critical command injection flaw in on-premises Arista VeloCloud Orchestrator is being actively exploited, prompting CISA to add it to the KEV catalog and require federal agencies to patch by July 30, 2026. Organizations should upgrade affected VCO versions immediately or restrict access and check logs for the listed malicious IPs.

A maximum-severity security flaw affecting on-premises versions of Arista VeloCloud Orchestrator has come under active exploitation in the wild. The vulnerability, tracked as CVE-2026-16812 with a CVSS score of 10.0, is an operating system command injection issue that could allow arbitrary code execution. Arista said successful exploitation may compromise the confidentiality, integrity, and availability of the orchestrator and the data it manages.

The affected releases are VCO 5.2.x before 5.2.3.14, 6.1.x before 6.1.3.4, 6.4.x before 6.4.2.4, and 7.0.x before 7.0.0.1. Arista said hosted and dedicated versions of VCO had already been addressed in advance, and it shared three IP addresses associated with the attacks: 8.19.75.217, 206.72.242.124, and 206.72.242.162. If compromise is suspected, Arista advised preserving VCO web access logs, backend application logs, system logs, database logs, and relevant file-system timestamps before remediation where operationally feasible.

CISA added CVE-2026-16812 to its Known Exploited Vulnerabilities catalog and required Federal Civilian Executive Branch agencies to apply the patch by July 30, 2026. Arista said that if immediate updating is not possible, operators should restrict access to the VCO web interface, monitor for known malicious source IPs, check for unexpected outbound activity, and review recent administrator activity. The article also notes that CISA added Fortinet FortiOS SSL-VPN CVE-2025-68686 to the KEV catalog and that Alibaba Fastjson CVE-2026-16723 is also under attack.

  • Arista said hosted and dedicated VCO versions were already addressed in advance, while the listed affected versions are specifically on-premises releases.
  • Arista warned that a compromised VCO platform may give attackers access to managed VeloCloud Edge devices, so remediation may need to include credential rotation, administrator activity review, device-state validation, and restoration or replacement of affected orchestrator instances.
  • If immediate patching is not possible, Arista recommends limiting VCO web interface access to trusted administrative networks and checking for unexpected outbound network activity from the VCO host.
  • Arista advises preserving multiple types of evidence before remediation where feasible, including VCO web access logs, backend application logs, system logs, database logs, and relevant file-system timestamps.

Beyond Shadow AI: The Netskope AI Report
netskope.com · 28 Jul 2026 04:15 UTC openai-codex / gpt-5.5

In plain words

Netskope published a new report saying that the risks around workplace AI have changed over the past year. Instead of mainly worrying about employees copying private information into AI prompts, organizations now face risks from AI systems being connected to internal data, coding tools that can run or suggest harmful code, and fake or tampered AI developer tools. This matters because companies using these AI services could expose sensitive information to people who should not see it or be tricked into using malicious software.

Summary
Netskope’s 2026 AI report says enterprise AI risk is shifting from users leaking data in prompts to architectural issues such as MCP-connected systems exposing unauthorized internal data, agentic coding tools creating code-execution paths, and attackers weaponizing AI-related developer supply chains.

Netskope published its latest AI report, covering analysis from June 2025 through July 2026. The report says security risks have shifted significantly since the prior report. It highlights architectural changes behind that shift and focuses on downstream policy violations, agentic coding apps, and the AI supply chain.

The report says downstream policy violations are now the primary architectural risk, rather than upstream data leakage from users pasting sensitive data into prompts. Netskope observed a fourfold increase in Model Context Protocol traffic in the past 10 weeks. The article says MCP bridges internal data stores with external models, creating a direct path for AI services to return sensitive data that users or agents are not authorized to access.

Netskope also says agentic coding tools have created new execution vectors, with Claude Code and Codex adoption rising to 75% and 58% of organizations, respectively. The article says every agentic interaction is now a potential execution vector for malicious code. It also says attackers are weaponizing the AI supply chain through trojanized developer tools, fake AI installers, and attempts to trick AI apps into surfacing malicious code and links to malicious web resources.

  • Controls focused only on stopping users from pasting sensitive data into AI prompts are no longer enough, because Netskope says the dominant risk now comes from AI services being connected to internal data sources and returning unauthorized information.
  • The rapid fourfold increase in Model Context Protocol traffic over just 10 weeks makes MCP a priority area for granular downstream inspection rather than a secondary AI integration detail.
  • The adoption rates cited for Claude Code and Codex show that agentic coding tools have quickly become mainstream in organizations, which makes code execution risk a broad enterprise issue rather than a niche developer concern.
  • Attackers are not only using AI as bait but are also targeting the AI development ecosystem itself through trojanized tools, fake installers, and manipulation of AI apps into surfacing malicious code or links.

  • 03Netskope observed a fourfold increase in Model Context Protocol traffic in the past 10 weeks, creating a path for AI services to return sensitive data that users or agents are not authorized to access.
  • 04The report says adoption of agentic coding tools has grown sharply, with Claude Code used by 75% of organizations and Codex used by 58% of organizations.
  • 05Netskope says attackers are weaponizing the AI supply chain through trojanized developer tools, fake AI installers, and attempts to make AI apps surface malicious code and links.
