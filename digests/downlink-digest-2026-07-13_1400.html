Cybersecurity researchers have identified a new macOS information stealer called CrashStealer that can harvest sensitive data from compromised systems. Jamf Threat Labs said the malware is implemented in native C++, unlike other stealers built on AppleScript droppers or Objective-C-based wrappers. The malware validates the victim’s login password locally before collecting data, encrypts harvested files with AES-GCM, and exfiltrates them over libcurl.

CrashStealer is distributed through a signed and Apple-notarized dropper delivered as a disk image named “Werkbit.app.” Because both the disk image and binary are notarized and use a valid developer ID, the dropper passes Gatekeeper checks. The download is served from werkbit[.]io and is gated behind a meeting PIN, while additional domains and shared backend infrastructure suggest the operation is part of a larger, multi-platform campaign.

After launch, the dropper contacts a GitHub repository to retrieve “sys.cache,” extracts a curl command, and downloads a shell script that stages “CrashReporter.dmg” in the /tmp directory. The malware establishes persistence as a LaunchAgent, resists analysis, unlocks the login keychain using the validated password, and collects browser credentials, cryptocurrency wallet extensions, password manager data, keychain material, and files from Documents and Downloads. The harvested data is packaged into a ZIP archive and sent to an attacker-controlled server at 179.43.166[.]242.
