Hackers Exploit N-central Flaws to Infect 21 Servers, Including 19 Running Hotfix 2

In plain words

Hackers are using newly disclosed weaknesses in N-able’s N-central management software to take control of servers and install software that secretly uses their computing power to generate cryptocurrency. At least 21 servers in several countries were affected, including 19 that had already installed a recent hotfix, showing that the prior update alone did not fully protect them. This matters because N-central servers help manage customers’ computers, so someone who takes over one could potentially gain powerful access across many organizations.

Summary
Attackers are actively exploiting the 4EverAble2Shell chain in N-able N-central to gain root access and deploy XMRig miners, including against servers already running Hotfix 2. Organizations should upgrade both N-central Agents and Probes to 2026.4 HF1 or later, disable Legacy API access, and investigate any suspected compromise as a full server breach.

N-able has restricted certain N-central features after disclosure of the 4EverAble2Shell and Agent2Shell flaws. In hosted environments, the company turned off the Legacy API by default and temporarily disabled Intune integration while it implements and validates additional protections. It advised customers to upgrade both N-central Agents and Probes to version 2026.4 HF1 or later; on-premises customers should also ensure Legacy API access is disabled.

The 4EverAble2Shell chain combines Apache Axis vulnerability CVE-2026-90436 with an N-central privilege-escalation weakness, allowing unauthenticated attackers to execute operating-system commands with root privileges. Researchers observed attackers using a shell script hosted at 157.20.241[.]16 to install XMRig Monero miners on 21 N-central servers across the United States, South Africa, Canada, the United Kingdom, Germany, France, and Sweden. Huntback reported that 19 of the affected servers were already running Hotfix 2 and warned that a successful intrusion should be handled as a full compromise because the server manages customer endpoints.

  • Installing Hotfix 2 alone did not stop the observed intrusions: 19 of the 21 affected servers were already running it, making the additional Agent and Probe upgrade guidance particularly important.
  • The observed cryptocurrency miner deliberately uses only half of a server’s available CPU cores, apparently to make its activity less noticeable.
  • N-able temporarily disabled its Intune integration and turned off the Legacy API by default in hosted environments while it develops and validates further protections.
  • Because a compromised N-central server manages customer endpoints, Huntback says an intrusion should be treated as a full compromise rather than simply removing the miner.
