Cursor Says Stolen Fireworks AI Key Led to Trojanized Claude Code Extension Incident
thehackernews.com · 15 Nov 2026 08:22 UTC openai-codex / gpt-5.6-terra

In plain words

Cursor says someone used a stolen Fireworks AI access key to view a limited set of its stored data, including some customer and company credentials. The intruder then used a stolen credential to place a harmful fake update for Anthropic’s Claude Code extension in Cursor’s extension store, where it could install a lasting remote-access tool on users’ computers. Up to 5,000 people may have downloaded the harmful version during an 11-hour period, while Uber and Notion also reported data exposure connected to the Fireworks AI incident. The case shows how a breach at one service provider can spread to multiple companies and put users’ accounts and computers at risk.

Summary
Cursor says a stolen Fireworks AI access key exposed limited customer and internal data, including some credentials, which an attacker later used to distribute a trojanized Claude Code extension through Cursor Marketplace. Up to 5,000 users may have received the malicious build during an 11-hour window on October 29, 2026.

Cursor said the compromise of Anthropic’s Claude Code extension on its marketplace stemmed from an access key it had issued to Fireworks AI. Fireworks exposed the key, enabling an attacker to copy data from a read-only storage bucket Cursor shared with the provider. The bucket held limited coding-agent traces from sessions not using Privacy Mode, including unredacted API credentials belonging to fewer than 0.01% of customers.

The attacker used exposed credentials to access selected Cursor software services and obtain limited support data, contact details, coding conversation summaries, archived non-production source code, and some credentials sent to Cursor support. On October 29, 2026, a stolen internal credential was used to place trojanized Claude Code extension versions 2.1.312 and 2.1.313 into Cursor Marketplace, where they were available for about 11 hours and may have reached up to 5,000 users. Cursor removed the extension, took its marketplace offline, rotated credentials, ended Fireworks AI access to shared data, and said it detected no additional malicious activity after November 1, 2026.

  • The incident shows a chain of exposure: a key shared with Fireworks AI led to access to Cursor data, and credentials found there were then used to alter software distributed through Cursor Marketplace.
  • Cursor’s Privacy Mode was a meaningful boundary in this event, as the company said it found no evidence that users who enabled it were affected.
  • Data retained from coding sessions, most dating to 2025 and permitted for model training, included credentials that had not been removed, creating a later pathway into Cursor’s internal tools.
  • The Fireworks AI incident had effects beyond Cursor: Uber reported that compromised provider credentials exposed driver’s license information, and Notion also confirmed data theft linked to the same incident.
