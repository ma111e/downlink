Organizations should urgently patch or mitigate the affected systems, especially because Apache Axis 1.x is end-of-life and lacks an official fix.

CISA added four actively exploited vulnerabilities affecting Synology DiskStation Manager, BerriAI LiteLLM, Apache Axis, and Vanderbilt University REDCap to its Known Exploited Vulnerabilities catalog. The flaws include three remote code execution issues with CVSS scores of 9.8 and a LiteLLM issue rated 8.8 that can enable code execution through a guardrails testing endpoint. CISA said the REDCap flaw can be triggered through crafted HTTP requests in a public survey context when an attacker knows a valid survey hash.

The Apache Axis flaw has reportedly been used alongside N-able N-central vulnerabilities to install cryptocurrency miners, but Axis 1.x is end-of-life and has no official patch. Separately, Safe Security observed REDCap exploitation that deployed a temporary web shell, loaded XMRig disguised as image files, and established persistence through cron and an added SSH key. The LiteLLM flaw has been used in LLMjacking activity to turn limited-access inference keys into administrator credentials, while the Synology DSM flaw has been linked to C3RB3R ransomware attacks on network-attached storage devices.

  • Apache Axis 1.x presents an unusual remediation problem because it is end-of-life and has no official patch; users are advised to migrate to Axis 2/Java or apply a build containing a specific July 2026 commit.
  • The REDCap exploitation described was designed to be less visible: attackers used a temporary web shell, loaded XMRig into memory, disguised it as image files, and made it appear as the syslog-ng service.
  • The LiteLLM flaw can turn a limited-access inference key into full administrator credentials, meaning a credential intended for restricted AI use can provide much broader control.
  • The four flaws are associated with distinct criminal outcomes—cryptocurrency mining, persistence in AI-service environments, and C3RB3R ransomware—rather than a single type of misuse.
  • CISA set different remediation deadlines, requiring action for the DSM, REDCap, and Axis flaws by November 21, 2026, while allowing until December 2, 2026 for the LiteLLM flaw.

This Health-ISAC daily briefing gathers several cyber-related developments that could matter to healthcare organizations, including possible exposure of Colla Health patient information and security weaknesses in widely used computer software. It also covers arrests connected to a group accused of collecting $40.5 million in payments, as well as government interest in the risks of medical devices that can operate on their own or be controlled from afar. These issues matter because failures in technology used by health organizations can put private patient information and dependable medical services at risk.

Summary
Health-ISAC’s daily briefing highlights urgent risks for healthcare defenders, including actively exploited Apache Roller and NGINX flaws, upcoming critical PHP patches, a potential Colla Health patient-data exposure, and ransomware arrests.

Health-ISAC’s November 19, 2026 Daily Cyber Headlines compiles cyber developments relevant to the health sector. The briefing covers suspected ransomware gang members arrested by Ukrainian police and the FBI in connection with $40.5 million in ransoms. It also includes Colla Health’s notice of potential patient-data exposure after unauthorized access to its Metabase application.

The roundup highlights a reported Apache Roller remote-code-execution issue being exploited in attacks, upcoming critical PHP security updates for all supported versions, and NGINX HTTP/2 flaws that could allow unauthenticated remote code execution. It also references Microsoft’s Windows Server 2028 security protections enabled by default. In addition, the briefing notes that regulators are seeking feedback on risks associated with autonomous and remotely operated medical devices.
