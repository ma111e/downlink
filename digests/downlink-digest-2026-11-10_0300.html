CISA Warns of Active Exploitation of OpenSSH, GPUStack, FreeSWITCH, and IBM Flaws

In plain words

The U.S. cyber agency CISA says attackers are actively taking advantage of four serious software flaws in OpenSSH, GPUStack, FreeSWITCH, and IBM Aspera Faspex. These flaws can let outsiders bypass sign-in checks, take administrator control, steal passwords and cloud-service secrets, change system settings, or run commands on affected computers. Attempts to misuse the OpenSSH flaw have already included looking for valuable information, adding access that can remain after the attacker leaves, and installing software for remote control or cryptocurrency mining. Organizations using these products, including U.S. federal agencies, are being urged to install the available fixes quickly.

Summary
CISA added critical flaws in OpenSSH, GPUStack, FreeSWITCH, and IBM Aspera Faspex to its KEV catalog after evidence of active exploitation. Organizations should urgently apply available patches, particularly for OpenSSH’s SSHole authentication-bypass flaw, which attackers are using for reconnaissance, persistence, botnet activity, and cryptomining.

CISA added four actively exploited vulnerabilities affecting IBM Aspera Faspex, SignalWire FreeSWITCH, OpenBSD OpenSSH, and GPUStack to its Known Exploited Vulnerabilities catalog. The flaws include authorization bypass, code injection, authentication bypass, and improper authentication issues, with CVSS scores ranging from 8.1 to 9.8. U.S. Federal Civilian Executive Branch agencies are recommended to apply fixes by November 12, 2026.

The OpenSSH issue, CVE-2026-123158 or SSHole, has faced exploitation attempts since November 6, 2026, and GreyNoise identified confirmed post-exploitation activity from six source IP addresses across 18 attack chains. Observed activity included reconnaissance, cloud metadata queries, attempts to obtain password hashes and root SSH keys, and changes to SSH authorized_keys files for persistent access. Attackers were also seen deploying TAC Agent, while watchTowr reported the flaw being used for botnet and cryptocurrency-mining activity.

  • The OpenSSH SSHole flaw was added to CISA’s catalog shortly after exploitation attempts began, with the article reporting activity from November 6 and a first GreyNoise honeypot observation on November 7.
  • Although Defused Cyber described SSHole activity as limited rather than widespread, GreyNoise had already confirmed 18 distinct post-exploitation attack chains from six source IP addresses.
  • Observed SSHole activity progressed beyond attempted access to persistence and credential collection, including changes to SSH authorized_keys files and attempts to obtain password hashes and root SSH keys.
  • GPUStack’s flaw can expose worker and cloud-provider secrets while also allowing persistent administrator API-key creation and code execution, creating several forms of lasting control from one issue.
  • The article reports active exploitation of all four flaws but provides public exploitation details only for OpenSSH and GPUStack, leaving the methods and scale affecting IBM Aspera Faspex and FreeSWITCH unknown.
Key Points
  • 01CISA added four actively exploited vulnerabilities affecting IBM Aspera Faspex, SignalWire FreeSWITCH, OpenBSD OpenSSH, and GPUStack to its Known Exploited Vulnerabilities catalog.
  • 02The OpenSSH flaw, CVE-2026-123158 or SSHole, is an authentication-bypass issue on Linux that was fixed in November 2026 and has faced exploitation attempts since November 6, 2026.
  • 03GreyNoise reported confirmed post-exploitation activity from six source IP addresses involving reconnaissance, cloud metadata queries, attempts to read password hashes and root SSH keys, and modification of SSH authorized_keys files.
  • 04Attackers were observed deploying TAC Agent, a Python-based remote-control tool that can execute shell commands, perform system reconnaissance, enumerate directories, transfer files, and update itself.
  • 05Federal Civilian Executive Branch agencies are recommended to apply fixes for the four vulnerabilities by November 12, 2026.
