PEEP Turns Chrome and Edge Into Post-Compromise Backdoors for Host Command Execution

In plain words

Researchers found a tool called PEEP that can make Chrome and Edge secretly act like a back door on a computer after the attacker has already broken in some other way. It pretends to be a bookmarks add-on, then can collect browsing history, cookies, open page details, and run commands on the computer. People using infected Chrome or Edge browsers are affected, and the bigger risk is that a trusted browser can be turned into a hidden way to steal accounts, take over sessions, and control files.

Summary
Researchers detailed PEEP, a post-compromise toolkit that turns Chrome and Edge into persistent backdoors by sideloading a fake bookmarks extension and using a native messaging host to run OS commands. It can steal browser data and cookies, hijack sessions, manage files, and maintain persistence by tampering with Chromium settings and policies.

Cybersecurity researchers disclosed details of PEEP, a Chromium-based post-exploitation toolkit that masquerades as a bookmarks extension for Chrome and Edge. SOCRadar said the tool requires prior administrative or code execution access and injects the extension directly into browser profiles. It bypasses Web Store checks and user prompts by forging Chromium Secure Preferences integrity values.

Once installed, PEEP polls its command-and-control server every 30 seconds over plaintext HTTP for new commands. It exfiltrates browsing history, active-tab metadata, session cookies, and other automatically collected data such as public IP address, locale, and time zone. The extension also uses a native-messaging executable, nm_host.exe, to run shell commands, manage files, and discover processes and services.

PEEP builds on the open-source RedExt browser data analysis and red teaming framework and expands it with installation routines, a native host bridge, heartbeat telemetry, an update channel, and a broader command set. The article says the activity is unattributed, though Chinese-language artifacts in the source code point to a Chinese-speaking threat actor. SOCRadar said PEEP turns Chrome and Edge into persistent backdoors that can support credential theft, session abuse, and command execution.

  • PEEP’s use of Chromium Secure Preferences tampering is notable because it helps the fake extension remain auto-enabled even though it is not distributed through official browser extension marketplaces.
  • The native-messaging bridge is a major escalation point because it turns browser-level access into operating system-level command execution and file management.
  • PEEP’s reliance on plaintext HTTP for 30-second command polling creates observable network behavior tied to the listed command-and-control endpoints.
  • The presence of a Linux Secure Preferences patching script shows the operators were replicating the browser-persistence behavior beyond Windows environments.
  • The exposed “/health” endpoint reported 34 agent entries, 10 active sessions, and 507 data records, but the article says these cannot be confirmed as real infections rather than test entries.
