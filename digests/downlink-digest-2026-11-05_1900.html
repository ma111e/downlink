watchTowr Labs analyzed two Barracuda Email Security Gateway flaws: CVE-2026-116606, a pre-authentication authorization bypass, and CVE-2026-111560, an OS command injection issue. The research compared ESG 9.4.0.027 with 9.4.0.029 and found that the vulnerabilities could be chained for unauthenticated remote command execution as root. Barracuda’s advisory lists ESG as affected by both flaws, while the command-injection issue also affects several other Barracuda products.

The authorization issue occurred when a failed password-change request returned a login-screen role object rather than stopping request processing, allowing module handlers to continue.   • The authorization bypass was caused by error handling that returned a low-privilege role object but did not terminate request processing, allowing later module handlers to run.

  • The injected time-zone value reached two command-execution paths, including fix_tz.pl, which the appliance ran with sudo and therefore executed commands as root.
  • The vulnerable backup-upload handler explicitly accepted requests under a permission rule of perm { 1 }, making it reachable once the password-change error path allowed request handling to continue.
