Railway says an October security incident exposed customer-stored AI provider keys that were used for an estimated $740,000 in unauthorized usage. The attacker initially exploited a previously unknown flaw to partly escape filesystem isolation in Railway’s build system and obtain a credential used by build servers.   • The financial outcome for affected customers depends heavily on the AI provider: AWS Bedrock and Google Gemini have fraud refund policies, OpenAI and SpaceXSI review claims individually, and Railway says it will cover Anthropic and OpenRouter costs when refunds are unavailable.
  • Railway replaced its prior build isolation approach with separate short-lived virtual machines and credentials limited to pushing one specific image after its hardening team reproduced a variation of the original escape.

In plain words

Microsoft researchers found that someone who can alter an AI model’s stored settings can secretly change fewer than 10 rarely used parts of it so that a chosen word or message makes it output an attacker’s command. This could affect organizations that use AI assistants to run software, because the assistant may carry out that command with whatever access it has, such as downloading and running a remote program. The altered model can still appear normal in ordinary testing, so teams need to verify where models came from, restrict what AI assistants can do, and require human approval for risky actions.

Summary
Microsoft researchers demonstrated that attackers with access to an AI model’s weights can implant a stealthy agent backdoor by directly modifying fewer than 10 rarely used neurons, causing malicious commands to be emitted when a trigger appears. The finding underscores the need to verify model provenance and weight integrity, sandbox agent actions, and apply least-privilege controls.

Microsoft researchers demonstrated Lazarus, a technique for placing a hidden backdoor in an AI model by directly changing fewer than 10 rarely used neurons, without retraining the full model. When a selected trigger appears in a user request or a tool’s output, the altered model can emit an attacker-chosen command for an AI agent to run with its existing permissions. The researchers tested the method on Nemotron-Terminal-8B, Qwen3.6-27B, and Gemma-4-31B-IT, and Microsoft said it has not observed threat actors using the technique.

On Nemotron-Terminal-8B, the team edited and tuned seven neurons in the final feed-forward layer using 23 example sessions, with the test command appearing in at least 98.8% of triggered sessions and none of the checked trigger-free sessions. The models could still pass ordinary evaluations, while the potential damage depends on what an affected agent is allowed to access or execute. Microsoft recommends verifying checkpoints against their declared base models, using trusted model sources and private registries, restricting agent permissions and network access, sandboxing generated code, and requiring approval for high-impact actions.

  • A command can require roughly one edited neuron per output token, meaning a short command can be implanted with only a handful of targeted changes.
  • The impact of the backdoor depends on the permissions granted to the AI agent rather than on the small size of the model edit.
  • A detector trained on Lazarus-style edits identified 91.4% of edited checkpoints without an original model for comparison, but falsely flagged 9.7% of clean checkpoints in a small test set.
  • Even with direct model changes, backdoored Qwen models retained most math-test performance, while their Terminal-Bench pass rate declined from 46.59% to 42.05%.
  • Comparing a checkpoint with its original base model is presented as the most reliable defense because Lazarus changes a small number of weight vectors substantially, unlike broad changes from ordinary fine-tuning or quantization.
