In plain words

Kaspersky says a group called Mirage Kitten is posing as recruiters on LinkedIn and other job sites, sending software developers fake coding tests that secretly install spying programs called NodeRabbit and PollCat. The known victims include aviation, aerospace, and financial technology organizations in Egypt, Ethiopia, and Afghanistan, with related files seen from several other countries. This matters because the attackers are using normal-looking job interviews and cloud services to reach people at important companies, making their activity harder to notice.

Summary
Kaspersky reports that Mirage Kitten is targeting aviation and fintech organizations in the Middle East and Africa with new cross-platform Node.js/JavaScript RATs called NodeRabbit and PollCat, delivered through fake recruiter coding challenges. The campaign marks a shift in the group’s tooling while continuing its use of LinkedIn lures, cloud-hosted infrastructure, and developer-focused social engineering.

Kaspersky uncovered two previously undocumented malware families, NodeRabbit and PollCat, while monitoring Mirage Kitten activity. Both are cross-platform remote access trojans delivered through spear-phishing messages on LinkedIn and other job search platforms that contain trojanized coding challenge archives. The campaign targeted aviation, aerospace, and fintech sectors across the Middle East and Africa, with victims identified in Afghanistan, Egypt, and Ethiopia.

NodeRabbit is built with Node.js and targets Windows, Linux, and macOS, with three variants recovered from systems in different countries. Its variants use persistence mechanisms such as registry run keys, scheduled tasks, cron entries, LaunchAgents, a fake Visual Studio Code extension, and Git-hook injection. Later variants added analysis-environment checks, corporate proxy support, updated command-and-control endpoints, and an expanded command set.

PollCat is written in obfuscated JavaScript and was found inside a React coding challenge called RankChallenge-react. It starts during application startup before OTP authentication is completed, registers with command-and-control servers, and supports commands for file operations, process execution, system inventory, and JavaScript execution. Kaspersky attributes the activity to Mirage Kitten with high confidence based on similarities with Retrograde/MiniFast, victimology, lure-hosting tradecraft, and infrastructure patterns involving Azure Websites and Cloudflare-backed domains.

  • The fake coding challenge README told targets not to modify server.js and prohibited AI assistants, even though an AI code review would likely have flagged the suspicious first-line import that launched the implant.
  • NodeRabbit’s later variants added developer-workflow persistence by abusing a fake Visual Studio Code extension and Git hooks, allowing the malware to relaunch during normal coding activity.
  • PollCat begins command-and-control registration before the victim enters an OTP code, so failed authentication blocks access to the visible challenge but does not stop the malware from running.
  • NodeRabbit Variant 2 includes corporate proxy handling, including fallback to curl.exe for NTLM/Negotiate authentication, indicating the operators designed it to work inside enterprise network environments.
  • Mirage Kitten used Azure Websites and Cloudflare-backed domains, and in some cases incorporated the targeted organization’s name into Azure subdomains to make command-and-control traffic appear more like normal business activity.
