CVE-2026-88772 is an actively exploited, pre-authentication memory-overflow flaw in Citrix NetScaler ADC and Gateway systems. It affects DTLS, a UDP-based secure communications feature enabled by default on NetScaler VPN virtual servers unless an administrator explicitly disables it. Citrix states that successful exploitation can lead to remote code execution or denial of service. The issue was one of eight vulnerabilities addressed in Citrix security bulletin CTX697096.

The article explains that an attacker can pass the DTLS cookie exchange without logging in, then send 120 specially constructed records on the same connection. NetScaler considers these records a completed 120-byte handshake message, but retains a linked chain containing roughly 174 KB of packet data. Vulnerable builds copy this entire chain into a fixed 35,840-byte scratch buffer without verifying that it fits, producing an overflow of about 137,825 bytes. The researchers show that the overflow can overwrite internal pointers and be developed into shellcode execution despite NX protections.

A patch comparison between NetScaler 14.1-73.30 and 14.1-73.37 shows that the fixed code tracks the scratch buffer’s remaining space and rejects packet-buffer chains that exceed it. Citrix recommends upgrading ADC and Gateway systems to 14.1-73.37 or later, 13.1-64.23 or later, and the listed corresponding FIPS and NDcPP fixed releases. The article also links to a detection-artifact generator intended to help organizations assess their own exposure.

  • The DTLS cookie exchange does not authenticate a user; it only confirms that the client can receive traffic at its claimed IP address, so the malicious records can be sent before login.
  • The crafted packets exploit a mismatch in how NetScaler interprets handshake fields: it treats each fragment as one byte for completion purposes while retaining nearly the entire large packet buffer for later copying.
  • Citrix’s patch addresses the flaw by tracking remaining room in the 35,840-byte scratch buffer and rejecting each packet buffer that would exceed that space, rather than changing DTLS reassembly itself.
  • Although the reassembled handshake message is reported as only 120 bytes long, the associated packet-buffer chain can contain about 174 KB of data, creating the oversized copy.
  • The article shows that the overflow can be developed beyond a crash into code execution by overwriting internal pointers and using fixed addresses in the non-PIE NSPPE binary.

    • Organizations that move to post-quantum website authentication should monitor public certificate records for newly issued older-style certificates, because those could enable a malicious fallback to weaker authentication.
    • Landmark-based MTCs improve efficiency but cannot fully replace standalone certificates because newly installed, offline, or out-of-date clients may not have the necessary browser updates.
