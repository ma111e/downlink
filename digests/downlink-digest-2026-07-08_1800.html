A China-linked threat cluster has been exploiting vulnerable Roundcube servers at U.S. and Canadian universities to steal credentials and deploy backdoor malware. Proofpoint tracks the activity as UNK_MassTraction and says it has been observed since May. The campaign focuses on physics and engineering departments, administrators and professors, and organizations involved in astrophysics, particle physics, or national security-related research.

The attack starts with a malicious email sent from compromised accounts or spoofed domains using a generic lure. When opened in a vulnerable Roundcube webmail client, the email triggers CVE-2024-42009, a cross-site scripting flaw that runs JavaScript in the victim’s browser and loads a payload called IceCube. Proofpoint describes IceCube as a fully featured Roundcube stealer that can collect usernames, passwords, cookies, two-factor authentication data, and browser information.

Proofpoint says IceCube uses helpers to exploit CVE-2025-49113, a Roundcube deserialization flaw, and tries to install SquareShell, a PHP webshell with remote code execution capabilities. If that fails, the malware downloads a shell script that loads VShell, a Go-based backdoor, directly in memory. Proofpoint assesses UNK_MassTraction is likely a China-aligned espionage actor but says the attribution is not high-confidence, and administrators are advised to apply the latest Roundcube security updates.

  • UNK_MassTraction appears to have targeted servers that were previously identified as vulnerable to both CVE-2024-42009 and CVE-2025-49113, indicating reconnaissance before the attacks.
  • The campaign can begin with a generic-looking email, but simply opening it in a vulnerable Roundcube webmail client can trigger the malicious JavaScript execution.
  • Proofpoint highlights that internet-facing mail servers should be treated with the same diligence as VPNs and other remote access nodes because attackers are using them as footholds into internal networks.
  • The attribution is based on overlapping infrastructure, Chinese-language artifacts in earlier phishing emails, and tactics associated with Chinese attacks, but Proofpoint explicitly says it is not a high-confidence assessment.
