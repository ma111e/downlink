Summary
Hackers hijacked HBO Max’s verified Reddit account to run more than 100 malicious ads that used ClickFix social engineering to trick Windows and macOS users into installing information-stealing malware. The campaign, linked to PasteSwitch, also promoted fake AI, developer, and cryptocurrency-wallet software.

Hackers compromised HBO Max’s verified u/hbomax Reddit account and used it to launch 108 malicious advertisements over about 48 hours. Researchers at Hudson Rock and ADAMnetworks linked the activity to a broader campaign called PasteSwitch. The ads impersonated HBO Max and also promoted fake AI tools, developer software, and macOS utilities, extending the campaign beyond streaming-service users.

The advertisements led visitors to convincing fake download sites that used ClickFix instructions, telling them to paste attacker-provided commands into Windows Run, PowerShell, or macOS Terminal. One macOS command downloaded and ran a script from infrastructure previously associated with PasteSwitch, while Windows chains used mshta and PowerShell and could disable Microsoft’s Antimalware Scan Interface. The campaign has delivered MacSync, AMOS helper, Amatera Stealer, and cryptocurrency clipboard hijackers, enabling theft of browser credentials, macOS passwords, Telegram data, wallet recovery phrases, and other information.   • The ClickFix approach avoids a conventional malware download by convincing victims to run the attacker’s commands themselves through built-in Windows or macOS tools.
  • PasteSwitch can alter its campaigns, target platform, delivered software, and cryptocurrency theft method depending on the visitor.
  • The same compromised HBO Max account was used to target audiences beyond streaming customers by advertising fake AI tools, developer software, and macOS utilities.

Summary
The Twitch Enhanced Viewer | JeetBot browser extension, installed by more than 30,000 users, exposes Twitch OAuth session tokens by forwarding them through JeetBot proxy servers in URL parameters. Users should remove the extension and revoke all Twitch sessions to invalidate potentially compromised tokens.

Socket reported that Twitch Enhanced Viewer | JeetBot, a browser extension available in the official Chrome and Firefox stores, captures Twitch OAuth session tokens and sends them through proxy servers operated by JeetBot. The extension has more than 30,000 installs and advertises functions including ad blocking, forcing 1080p playback, bypassing region restrictions, and collecting channel points. JeetBot is described as a commercial Russian-language streaming and chatbot service offering tools for Twitch, Kick, and VK Live.

The extension redirects Twitch video playlist requests through a proxy and appends the user token as an auth= URL parameter, causing it to be recorded in clear text in proxy-server request logs. Socket said this occurred for every channel a user watched except ten Russian-language channels hardcoded into the extension. Earlier versions included more explicit token-transmission mechanisms, and the Firefox listing contained a developer disclaimer acknowledging that prior versions sent Twitch OAuth tokens to its server. Socket recommends users remove the extension, disconnect all Twitch sessions, and sign in again to invalidate any forwarded tokens.

  • The extension’s Chrome privacy disclosure said the developer would not collect or use user data, despite the extension forwarding Twitch OAuth tokens through its proxy infrastructure.
  • Putting authentication tokens in URL parameters makes them available in routine proxy request logs, creating a direct retrieval path for the proxy operator.
  • The token-forwarding behavior reportedly occurred for every channel watched except ten Russian-language channels hardcoded into the extension.
  • The Firefox listing included a developer disclaimer acknowledging that previous versions transmitted users’ Twitch OAuth tokens to its server.
