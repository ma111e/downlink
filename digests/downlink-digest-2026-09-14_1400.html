In plain words

Researchers found that someone who already controls a server and can briefly handle it in person could add a cheap device that makes the server ignore selected memory updates without raising an alarm. This can weaken Intel and AMD protections used by major cloud providers to keep customers’ data private while it is being processed. The work does not show that AWS, Microsoft Azure, or Google Cloud have been breached, but it shows that a rogue employee, supply-chain tampering, or a seized machine could potentially defeat these protections. There is no simple software-only fix because the underlying weakness is in how current server hardware handles memory.

Summary
Researchers demonstrated DDRop, a low-cost physical interposer attack that silently drops DDR5 memory writes and exploits missing freshness protections in Intel TDX, Scalable SGX, and AMD SEV-SNP. An attacker with server software control and brief physical access could undermine confidential-computing workloads, and fully addressing the flaw requires future hardware designs with memory freshness guarantees.

Researchers disclosed DDRop, a hardware attack that silently drops selected DDR5 memory writes, causing a processor to read older encrypted data as if the new update had succeeded. It affects Intel TDX, Intel Scalable SGX, and AMD SEV-SNP, which are confidential-computing technologies used in cloud servers. The attack requires an adversary who already controls server software and can briefly access the machine to install a small interposer board between the processor and a memory module.

The interposer forces an error on the memory command bus, then blocks the memory module from reporting that error, so the module discards a write without the processor being notified. On Intel TDX, researchers used this behavior to read a victim virtual machine’s private memory, enable debug mode, and alter launch measurements under specified integrity settings; on AMD SEV-SNP, they demonstrated copying one victim page’s contents into another during page relocation. The researchers said there is no simple patch because the underlying memory-encryption designs lack a way to verify that data is the newest version, although software measures and stronger future hardware designs could raise protection.

  • DDRop does not need to decrypt memory or alter encrypted contents directly; it exploits the fact that older encrypted values can still be accepted when a new write is silently discarded.
  • The interposer hides a dropped write by deliberately causing an error on the memory command bus and then blocking the memory module’s error report, leaving the processor unaware that the update failed.
  • Intel TDX’s optional cryptographic-integrity mode would block some demonstrated cross-virtual-machine effects, but the researchers argue it would not prevent forgery of an attacker-controlled machine’s own attestation because it still lacks a way to detect reused older data.
  • The required hardware is estimated at about $159 in parts, can be installed in minutes, and can then be operated entirely through software, making a single brief physical-access opportunity sufficient for the described setup.
  • The researchers identified limited software measures, such as verifying important writes and checking for an interposer at startup, but stated that complete protection would require future memory-encryption hardware with both integrity and freshness protections.
Key Points

  • 02DDRop requires an attacker to control server software and briefly access the machine to install an interposer between the processor and a memory module, with parts costing about $159.
  • 03The researchers demonstrated impacts on Intel TDX, Intel Scalable SGX, and AMD SEV-SNP; on Intel TDX, they showed victim-memory reading, debug-mode activation, and launch-measurement forgery under specified conditions.
  • 04AWS, Microsoft Azure, and Google Cloud offer affected confidential-computing technologies, but the researchers said they have no evidence that DDRop or comparable active interposers have been used outside a laboratory.
