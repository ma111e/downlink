Researchers H0j3n and Aniq Fakhrul published a working exploit on July 24 for an Active Directory Certificate Services issue they codenamed Certighost. The flaw lets a low-privileged Active Directory user obtain a certificate for a Domain Controller and authenticate as that machine. Microsoft patched the issue ten days earlier as CVE-2026-54121, classifying it as improper authorization with a CVSS score of 8.8.

The attack requires network access and a domain account, but no administrator rights or user interaction. In the researchers’ test, a normal Domain Users account could create a computer account under the default ms-DS-MachineAccountQuota value of 10 or reuse one it already controlled. Because Domain Controller accounts have directory replication rights, the resulting Kerberos credential can retrieve the krbtgt secret through DCSync.

The bug is in an AD CS enrollment fallback known as a chase, where the CA followed requester-supplied SMB and LDAP targets without first proving they were real Domain Controllers. Microsoft’s July update adds validation before the CA follows a chase, including checks for DNS name matching, Domain Controller account attributes, and SID comparison. Organizations running an Enterprise CA should install Microsoft’s July 14 updates on AD CS hosts, while a lab-tested chase-disable mitigation is available for those that cannot patch immediately.

  • The exploit chain can work with a normal Domain Users account when the default ms-DS-MachineAccountQuota value of 10 allows that user to create a computer account, meaning the default configuration can help satisfy part of the attack requirements.
  • The vulnerable behavior came from the CA trusting requester-supplied chase targets over SMB and LDAP before verifying that the target was a real Domain Controller.
  • Microsoft’s patch added validation that rejects IP literals, overlong names, and LDAP metacharacters, requires exactly one matching Domain Controller computer object, and performs a later SID comparison to block substitution.
  • The temporary mitigation to clear the chase flag may break legitimate certificate enrollment flows, so the researchers recommend staging it first and treating the July update as the permanent fix.
  • No primary source reviewed by The Hacker News reported in-the-wild exploitation as of July 24, but the article emphasizes that this absence of reporting does not prove exploitation has not occurred.
