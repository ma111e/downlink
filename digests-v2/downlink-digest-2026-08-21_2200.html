Introducing EchoBench: A Human Calibrated Benchmark for Autonomous Pentesting

NetSPI introduced EchoBench, a benchmark that evaluates autonomous web application pentesting systems by comparing their validated findings against a measured cohort of human associate pentesters. Its main value is giving AI pentesting scores a human-calibrated denominator, with performance broken down by fidelity, difficulty, OWASP coverage, and repeatability.

NetSPI introduced EchoBench, an empirically calibrated human outcome benchmark for evaluating autonomous AI web application pentesting. The benchmark is designed to answer how an autonomous AI system compares to human pentesters on the same applications and under the same finding definitions. An ECHO score of 100 marks parity with a measured human cohort, which currently consists of associate pentesters from NetSPI University.

EchoBench evaluates the model and harness configuration together, including elements such as prompts, tools, browser environment, context handling, execution policy, report generation, and orchestration logic. It scores four components: finding fidelity, difficulty-reach, OWASP breadth, and repeatability. These components are combined with geometric means so that one strong area cannot hide a serious weakness in another area.

The current benchmark corpus contains five web applications and 184 canonical finding IDs, with 173 findings assigned human difficulty labels so far. The human reference draws from NetSPI University program data spanning five years of cohorts and roughly 300 completed application assessments, with the current matched snapshot showing application-equal human means of 64.6 percent precision, 57.9 percent recall, and 59.3 percent F1. Every published score is intended to include the reference cohort, configuration, target metrics, component values, provenance views, repeat coverage, cost, runtime, model charges, and infrastructure use as separate evidence.

  • EchoBench uses geometric means so a system cannot compensate for a near-zero weakness in one area, such as OWASP breadth or repeatability, with strong performance in another area.
  • The same raw AI performance can mean different things on different applications because the human reference F1 ranges from 71.2 percent on one public application to 38.9 percent on another.
  • The benchmark separates public and proprietary targets before combining them, which is meant to reveal whether familiarity or provenance affects performance.
  • Repeatability is judged by lower-quartile performance, and failed, timed-out, or unusable runs receive zero rather than being discarded.
  • Pass-at-k results are kept outside the main ECHO score because retry strategy and report selection are treated as separate operating policies rather than core single-run assessment performance.

NetSPI introduced EchoBench, a new way to judge automated AI tools that look for security problems in web applications by comparing them with real results from trained human testers. It uses the same five applications and the same set of 184 known reportable issues, so a score has a clear human reference instead of being just a standalone percentage. This matters for researchers, builders, consultants, and security teams because it helps show whether an AI testing system can actually do the job reliably, including on harder issues and on bad runs, rather than only looking good in a vague benchmark.
