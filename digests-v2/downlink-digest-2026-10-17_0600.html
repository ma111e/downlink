Hackers Use Compromised ConnectWise Credential to Sign In to 173 Microsoft 365 Tenants

A compromised ConnectWise Cloud Backup credential was used to access 173 Microsoft 365 customer tenants, potentially exposing email, files, Teams data, and directory information through the app’s broad permissions. Organizations using the app should disable it, investigate Entra service-principal and audit logs, and review newly added application credentials until ConnectWise completes credential rotation.
KEY POINTS
  • 01Unknown threat actors used a compromised ConnectWise Cloud Backup Microsoft 365 credential to obtain Microsoft Graph tokens and sign in to 173 partner or customer tenants.
  • 02ConnectWise Cloud Backup has broad access to Microsoft 365 data, including mailboxes, OneDrive, SharePoint, Teams, and directory data, so its compromised credential could provide comparable access in each tenant where the app was installed.
  • 03Huntress observed activity from IP address 144.172.64.128 on October 15, with the actor moving through tenants in sorted GUID order within seconds, suggesting scripted targeting.
  • 04In one partner tenant, a separate ConnectWise Cloud Management app for Microsoft Teams added itself to the Global Administrator role and added new client secrets to two other trusted applications.
  • 05ConnectWise closed Cloud Backup application access until further notice, said it found no evidence that partner backup data was compromised, and advised customers to review relevant Microsoft Entra service-principal sign-in logs.

Unknown threat actors used a compromised Microsoft 365 credential for ConnectWise Cloud Backup, formerly SkyKick, to obtain Microsoft Graph tokens and access 173 partner or customer tenants. Huntress observed the activity from IP address 144.172.64.128 on October 15, with the actor moving through tenants in sorted GUID order seconds apart. ConnectWise Cloud Backup is granted broad permissions to back up customer Microsoft 365 data, including mailboxes, OneDrive, SharePoint, Teams, and directory information.

The stolen credential could give an attacker the same access the backup application has in every tenant where it is installed, potentially exposing customer email, files, chats, and directory data. In one partner tenant, Huntress found a separate ConnectWise Teams application assigning itself the Global Administrator role and adding new secrets to two trusted applications, which could extend access to other privileged tools. ConnectWise closed Cloud Backup application access until further notice and said it found no evidence that partner backup data had been compromised; affected organizations are advised to disable the app, review service-principal sign-in and Entra audit logs, and check for credentials added since October 13, 2026.

  • Revoking user sessions does not stop this form of access; disabling the application prevents new tokens, but tokens already issued can remain valid for up to 90 minutes.
  • Some directory-reading activity through Microsoft Graph may leave no audit trail, so organizations are advised to act even if they cannot find proof that data was accessed.
  • Adding new credentials to trusted MSP-management or security applications can extend access beyond a single tenant because those tools may already be authorized in customer environments.
  • The relevant evidence is in Microsoft Entra service-principal sign-in logs rather than the default user sign-in logs, and suspicious activity can be identified by comparing source IP addresses with the application’s expected Azure private IPv6 traffic.

Someone obtained a login credential for ConnectWise Cloud Backup, a service that managed IT providers use to back up customers’ Microsoft 365 data, and used it to enter 173 customer organizations’ accounts. Because the service was allowed to access email, files, chat messages, and organization information in each customer account, the intruder may have been able to view or change that data. This matters because one stolen vendor credential can put many unrelated businesses at risk at once, including their clients’ information, and the article says some related access could leave little or no record.
