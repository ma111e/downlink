KEY POINTS
  • 01Signal plans to block screenshots of messages by default on certain Apple and Google operating systems where it detects AI assistants trying to read on-screen text.
  • 02The company says the change is intended to limit the risk that operating-system AI agents scan Signal conversations and make captured data available to local databases or remote servers.
  • 03Users will be able to disable the screenshot restriction in Signal’s settings.
  • 04Signal says blocking screenshots is incomplete because AI agents could potentially access content already on a device through the file system.
  • 05Signal called on Apple, Google, and Microsoft to provide clearer documentation and controls that let users and app developers limit AI-agent access to application data.

Signal announced that it will block screenshots of messages by default on certain Apple and Google operating systems when it detects AI assistants attempting to read on-screen text. The company said the change follows a similar restriction it previously applied to Microsoft Windows 11. Users will be able to turn off the screenshot block in Signal’s settings.

Signal said operating-system AI agents can scan screen content to answer user requests, potentially moving captured conversation data into local databases or remote servers outside Signal’s control. It warned that screenshot blocking is only a partial measure because AI agents may also access data already stored on a device through the file system. Signal called on Apple, Google, and Microsoft to provide clearer documentation and controls that allow users and app developers to restrict AI-agent access without significantly harming the user experience.

  • Signal’s screenshot blocking is a limited safeguard rather than a complete solution, because the company says AI agents may also retrieve data already stored on a device through its file system.
  • Signal says it cannot apply the same restriction on macOS, highlighting that app privacy protections can depend on controls made available by operating-system providers.
  • The company argues that inadequate technical documentation about AI agents makes it harder to provide reliable privacy and security protections for Signal’s users.
  • Although screenshots will be blocked by default, users can choose to disable the protection in Signal’s settings.

Signal says it will normally prevent people from taking screenshots of chats on certain Apple and Google devices when built-in AI helpers may be able to read what is on the screen. This is meant to protect Signal users and everyone they message, because the AI helpers could copy conversation content to places outside Signal’s control. People can turn the screenshot block off in Signal’s settings, but Signal says the larger problem remains because these helpers may have other ways to access information already stored on a device.

Webworm Suspected of Modifying SoftEther VPN to Evade Detection and Hide Remote Access

China-aligned Webworm is suspected of rebuilding SoftEther VPN Bridge as “NtMonitor VPN” to remove recognizable fingerprints and conceal covert remote access. The modified tool changes HTTP endpoints, handshake watermarks, and configuration storage for stealth rather than adding new capabilities.
KEY POINTS
  • 01Rapid7 assessed with moderate confidence that the China-aligned Webworm group is using a modified build of SoftEther VPN Bridge to conceal remote access to compromised networks.
  • 02The Windows executable netcapa.exe is based on SoftEther VPN Bridge version 4.44 build 9807 and is rebranded as “NtMonitor VPN,” presenting itself as Network Monitor Software.
  • 03The altered tool replaces SoftEther’s usual HTTP endpoints and GIF-based handshake marker with ordinary-looking endpoints and a PNG-based marker to evade detection signatures.
  • 04The modified build renames and encrypts its configuration file as setting.conf, which begins with the ASCII magic bytes “RCEN.”
  • 05Rapid7 found no new functionality in the modified tool, indicating that its changes are focused on stealth rather than added capabilities.

Rapid7 assessed with moderate confidence that the China-aligned Webworm threat actor is using a customized version of SoftEther VPN Bridge to establish covert remote access to compromised networks. The Windows executable, netcapa.exe, is a modified build of SoftEther VPN Bridge 4.44 build 9807 that has been rebranded as NtMonitor VPN and presented as Network Monitor Software. Webworm has previously targeted government entities, IT services, and electric-power companies across Russia, Georgia, Mongolia, and other Asian nations. The artifact was uploaded to VirusTotal around mid-January 2026.

The altered build replaces SoftEther’s usual HTTP paths with the benign-looking endpoints /update/alive.cgi and /update/picture.cgi, and it swaps the standard GIF-based handshake watermark for a PNG-based one. It also renames the configuration file to setting.conf, encrypts it with a custom algorithm, and embeds a minimized required resource archive into the executable. Rapid7 found that the attackers did not add new functionality, indicating that the modifications were intended primarily to remove recognizable detection fingerprints and make the tool blend in with ordinary web activity. Despite the rebranding, the executable retains a PDB path and some registry references that identify its SoftEther origins.

  • The modified program still contains a PDB file path identifying it as SoftEther VPN Bridge, meaning it conceals its network behavior rather than its underlying identity from reverse engineers.
  • Webworm’s changes focus on replacing recognizable detection indicators, including known web paths and the GIF-based handshake marker, without adding new operational functionality.
  • Although it is rebranded as NtMonitor VPN, some registry paths continue to reference “SoftEther Project,” showing that the renaming was incomplete.
  • The required SoftEther resource archive was reduced and embedded within the executable, increasing the binary’s size by approximately 1.5 MB while avoiding a separate runtime file.

Researchers believe the China-aligned Webworm group altered a legitimate remote-connection program, SoftEther VPN Bridge, and disguised it as network-monitoring software. The group may use it to maintain hidden access to organizations it has compromised, including government, IT services, and electric-power organizations in Russia, Georgia, Mongolia, and other Asian countries. The changes do not add new features, but make the tool look more like normal web activity and harder for security software to recognize, which can help attackers stay hidden longer.
