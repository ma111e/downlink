  • 01SEO-optimized fake GitHub repositories impersonating LastPass and at least 39 other companies distribute the previously undocumented Rapuncel information stealer.
  • 02Victims are redirected from fake download buttons to ZIP archives inflated to as much as 148 MB, which contain a renamed Microsoft Visual Studio CoreCLR Debugger configured to load a malicious DLL.
  • 03The campaign deploys a Microsoft-signed Alinubx.sys kernel driver disguised as an NVIDIA component that is designed to terminate 145 antivirus and endpoint-detection processes.
  • 04Rapuncel steals credentials from 25 browsers, data from 30 cryptocurrency wallets, Discord, Steam, and Telegram session credentials, Windows Credential Manager contents, selected documents, screenshots, and system information.
  • 05Rapuncel persists through a Windows service and uploads compressed stolen data to 2.26.126[.]50 using an HTTP-formatted request over raw TCP.

SEO-optimized GitHub repositories impersonating LastPass and at least 39 other companies are distributing a previously undocumented information stealer named Rapuncel. Victims searching for LastPass Authenticator or other software can be redirected from fake download buttons to payload servers that provide ZIP files inflated to up to 148 MB. The archives contain a renamed Microsoft Visual Studio CoreCLR Debugger, vsdbg.exe, configured to load a malicious DLL.

The installer deploys Rapuncel and a Microsoft-signed Alinubx.sys kernel driver disguised as an NVIDIA component, nvfsflt64.sys. The driver is designed to terminate 145 antivirus and endpoint detection and response processes, including by bypassing Protected Process Light protections, and it is not currently on Microsoft’s vulnerable drivers blocklist. Once defenses are disabled, Rapuncel can steal browser credentials, cryptocurrency wallet data, session credentials, Windows Credential Manager contents, selected documents, screenshots, and system information, then persist through a Windows service and upload compressed data to an external endpoint.

  • The campaign uses a driver signed through Microsoft’s Windows Hardware Compatibility Publisher chain that is not currently on Microsoft’s vulnerable drivers blocklist, allowing it to terminate security products.
  • The driver can bypass the Protected Process Light safeguard used by many security products by opening target processes as kernel code before killing them.
  • Rapuncel bypasses Google’s app-bound encryption in Chrome, Edge, and related browsers by placing a helper component inside the browser and using its own elevation service.
  • Its Windows service persistence means security tools that restart after being disabled can be killed again before the information stealer runs.

Criminals are creating fake GitHub download pages that pretend to offer LastPass Authenticator and software from at least 39 other companies. People who find these pages through search results may download a program that shuts down security software and steals saved browser passwords, cryptocurrency wallet data, chat and gaming account sessions, documents, screenshots, and other computer details. This matters because the stolen information can let criminals take over accounts, access money, and keep stealing data even after a computer restarts.

New WordPress Click2Shell Flaw Forces Theme Installs, Can Chain to Code Execution

WordPress patched the Click2Shell flaw, which lets a crafted link force a logged-in administrator’s browser to install and preview an inactive theme from WordPress.org. When chained with a separate vulnerable theme, the issue can lead to server-side code execution, so site owners should update to WordPress 7.1.1 or the applicable supported security release.
KEY POINTS
  • 01WordPress released security updates, including WordPress 7.1.1, to fix Click2Shell, a flaw that can cause a logged-in administrator who opens a crafted link to install and preview an inactive theme from WordPress.org.
  • 02The core Click2Shell flaw cannot install an arbitrary theme ZIP by itself; it installs a legitimate theme selected by the attacker from the official WordPress.org directory.
  • 03Pwn.ai demonstrated that Click2Shell could be chained with a separate flaw in the Mobile Repair Zone theme to run attacker-controlled code on the server.
  • 04The forced-installed theme remains inactive, so the site’s appearance does not change, but WordPress’s Customizer can load a theme’s PHP code while preparing a preview.
  • 05The article states that no evidence shows Click2Shell has been used in real attacks, and that updating WordPress core closes the demonstrated attack.

WordPress released security updates, including WordPress 7.1.1 on September 17, to address Click2Shell, a flaw reported by pwn.ai. A crafted link opened by a logged-in administrator could cause WordPress to install a legitimate theme selected by an attacker from the WordPress.org directory without the administrator clicking Install. The installed theme stays inactive, so the site’s appearance does not change, and the article says there is no sign the flaw has been used in real attacks.

The issue stems from two WordPress components interpreting the same link differently, allowing attacker-supplied punctuation to direct WordPress’s own page script to click the Install button. The administrator’s active session supplies the permissions and security token required for installation, so an attacker does not need to provide them. Pwn.ai showed that the forced installation could be chained with a separate weakness in the Mobile Repair Zone theme, whose background handler could download and run code without checking permission or a security token; site owners should update WordPress core to 7.1.1 or the matching supported-branch update.

  • The attack relies on two WordPress components interpreting the same link differently, allowing attacker-added punctuation to redirect WordPress’s own page script to the Install button.
  • An attacker does not need the administrator’s password or installation security token because the logged-in administrator’s existing browser session supplies both permissions when the crafted link is opened.
  • A theme need not be activated to create risk: WordPress can load its PHP code while generating a preview in the Customizer.
  • The demonstrated path to server-side code execution required two separate issues—the WordPress core forced-install flaw and an unauthenticated package-download handler in the Mobile Repair Zone theme.
  • The article says there is no separate workaround from WordPress or pwn.ai for sites that cannot update immediately, making the applicable WordPress security update the stated remediation.

WordPress released an update to fix a flaw that could let a malicious link make a logged-in site administrator install a real theme without pressing the Install button. The site’s appearance would not visibly change, but researchers showed that if the added theme has its own weakness, an attacker could run their own commands on the website’s server. Website owners using affected WordPress versions should update because the problem could give attackers control over a site, although there is no sign it has been used in real attacks.
