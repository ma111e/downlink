F5 releases emergency patches for critical BIG-IP RCE flaws

F5 released emergency patches for five critical BIG-IP flaws that unauthenticated attackers could exploit for remote code execution, plus a high-severity APM denial-of-service bug. With no mitigations available and thousands of BIG-IP systems exposed online, administrators should apply the out-of-band hotfixes immediately.
KEY POINTS
  • 01F5 released out-of-band hotfixes for five critical BIG-IP flaws that unauthenticated remote attackers can exploit to execute arbitrary code on vulnerable systems.
  • 02The affected flaws involve BIG-IP Access Policy Manager and the BIG-IP iRules feature, and F5 said no mitigation measures are available beyond installing the released hotfixes.
  • 03F5 also issued engineering hotfixes for CVE-2026-126822, a high-severity BIG-IP APM issue that unauthenticated attackers can use to cause denial of service.
  • 04Shadowserver tracks more than 177,000 internet-exposed BIG-IP instances and over 14,600 IP addresses with BIG-IP APM fingerprints.
  • 05F5 has not reported these newly disclosed flaws as exploited, but CISA has listed seven F5 vulnerabilities as actively exploited since November 2021.

F5 released out-of-band hotfixes for five critical BIG-IP vulnerabilities affecting the Access Policy Manager (APM) and the iRules scripting feature. The flaws, tracked as CVE-2026-121805, CVE-2026-120292, CVE-2026-120285, CVE-2026-116953, and CVE-2026-123637, are stack-based buffer overflows that unauthenticated remote attackers can exploit to execute arbitrary code. F5 also issued engineering hotfixes for CVE-2026-126822, a high-severity BIG-IP APM integer-underflow issue that can be used to cause denial of service. The company said there are no mitigation measures for these issues and advised customers to install the hotfixes.

Shadowserver tracks more than 177,000 internet-exposed BIG-IP instances and over 14,600 IP addresses with BIG-IP APM fingerprints, although the figures may include honeypots and already patched devices. F5 has not said that the newly disclosed vulnerabilities are being exploited, but the article notes that threat groups have previously used F5 flaws to breach networks, map internal servers, take over devices, deploy data-wiping malware, and steal files. CISA has identified seven F5 vulnerabilities as actively exploited since November 2021, including four used by ransomware groups. F5 also patched a separate critical BIG-IP APM flaw, CVE-2026-94127, in September that was being exploited in zero-day remote-code-execution attacks.

  • The absence of any stated workaround means organizations with vulnerable BIG-IP systems must rely on F5’s out-of-band hotfixes rather than compensating controls described in the article.
  • The reported internet exposure figures do not establish how many systems remain vulnerable, because Shadowserver’s counts may include honeypots and already patched devices.
  • Although F5 has not identified exploitation of these newly disclosed flaws, the company’s recent history includes a BIG-IP APM remote-code-execution flaw that was actively exploited as a zero-day.
  • CISA has recorded seven actively exploited F5 vulnerabilities since November 2021, including four that ransomware groups used.

F5 has issued urgent fixes for serious weaknesses in its BIG-IP products, which many organizations use to manage access to their online systems. Without the fixes, an outsider could potentially take control of affected systems or make them stop working, and F5 says there are no temporary workarounds. This matters because more than 177,000 BIG-IP systems are visible on the internet, and criminals and state-backed groups have repeatedly used F5 flaws to break into organizations, steal files, and disrupt operations.

Windows 11 KB5132057 update released with 28 changes and fixes

Microsoft released the optional Windows 11 KB5132057 preview update for versions 25H2 and 26H2, adding 28 non-security improvements including a redesigned Windows Search, improved Windows Hello facial recognition in dark rooms, and a new Run dialog. As a preview update, it is intended for testing before broader rollout in the next Patch Tuesday release.
KEY POINTS
  • 01Microsoft released the optional KB5132057 cumulative preview update for Windows 11 versions 25H2 and 26H2, with 28 changes and fixes but no security updates.
  • 02The update introduces a WinUI 3-based Windows Search experience that removes promotional content from web results and adds direct actions such as changing dark mode, Bluetooth, brightness, and volume settings.
  • 03KB5132057 improves Windows Hello facial recognition in dark rooms when users enable automatic screen-brightness adjustment during face recognition.
  • 04The update adds a redesigned Run dialog that users can enable under Settings > System > Advanced, and it fixes a File History issue that could prevent the restore interface from finding backups.
  • 05Microsoft said a limited number of consumer and business devices may experience one extra restart during installation as part of a Secure Boot certificate update process.

Microsoft released the optional KB5132057 cumulative preview update for Windows 11 versions 25H2 and 26H2. The non-security update contains 28 changes and fixes, allowing IT administrators to test improvements before they are expected to reach general availability in the next Patch Tuesday release. It updates the two versions to builds 26200.10075 and 26300.10075, respectively.

Key additions include a WinUI 3-based Windows Search experience with promotional web content removed, faster indexer-based “Search from This PC” searches in File Explorer, and inline Windows Search actions for settings and Phone Link tasks. Windows Hello facial recognition can work in dark rooms when users enable automatic screen-brightness adjustment, and a redesigned Run dialog can be enabled in Settings. The update also fixes a File History restore issue, adds passwordless web sign-in support for Microsoft Entra hybrid-joined devices, and may cause a limited number of devices to restart once more during installation because of a Secure Boot certificate update.

  • IT administrators can use KB5132057 to test upcoming Windows changes before they are included in the next month’s Patch Tuesday release, but the update does not provide security fixes.
  • Microsoft Entra hybrid-joined devices can now use passwordless web sign-in at the lock screen with FIDO2 security keys, phone passkeys, or Temporary Access Passes while retaining access to on-premises resources through a Kerberos ticket.
  • Users who do not enable Windows Update’s option to receive the latest updates early must manually select “Download and install” to receive this optional preview update.
  • A limited number of devices may restart an additional time during installation because a Secure Boot certificate update is being applied.

ROMULUS ClickFix Attacks Deliver RAT That Can Spy on Users and Control PCs

ROMULUS is using ClickFix lures and DLL sideloading to deliver CNCMachineRMS, a newly documented RAT that can remotely control infected PCs, capture screens, microphones and cameras, and steal files. The campaign reflects the growing sophistication and breadth of ClickFix operations, which increasingly use fake verification prompts to trick users into running malicious commands.
KEY POINTS
  • 01Blackpoint Cyber reported that the ROMULUS malware delivery platform uses ClickFix-style lures to distribute CNCMachineRMS and Legion Loader through separate infection chains.
  • 02One ROMULUS chain uses a malicious MSI installer masquerading as Stardock Smart DeElevation Tool to launch a DLL sideloading sequence that executes CNCMachineRMS.
  • 03CNCMachineRMS can provide remote desktop control, screen streaming, microphone and camera capture, file management, system reconnaissance, and on-demand execution of additional payloads.
  • 04CNCMachineRMS communicates with attacker-controlled infrastructure using DNS over HTTPS.
  • 05The article describes multiple other ClickFix campaigns that use fake verification prompts, deceptive ads, compromised websites, and impersonated pages to deliver remote-access tools and information-stealing malware.

Blackpoint Cyber reported that the ROMULUS malware delivery platform is using ClickFix-style lures to distribute a previously undocumented remote-access trojan called CNCMachineRMS, as well as Legion Loader through separate infection chains. ROMULUS retains ClickFix techniques and signed-binary DLL sideloading while changing the applications and loaders used to deliver its payloads. The same CNCMachineRMS implant was also previously delivered through malicious ChatGPT Custom GPT lures.

One ROMULUS chain uses a malicious MSI installer named IconEdit2Turb.msi, executed with msiexec.exe through PowerShell and disguised as Stardock Smart DeElevation Tool. The installer launches a DLL sideloading chain involving a malicious DLL, I++u.dll, which decodes embedded shellcode to run CNCMachineRMS. The RAT can remotely control desktops, stream screens, capture microphone and camera data, manage files, perform system reconnaissance, and run additional payloads, communicating with attacker-controlled infrastructure using DNS over HTTPS. The report comes amid numerous ClickFix campaigns using fake verification prompts, compromised websites, deceptive ads, and impersonated pages to deliver remote-access tools and information-stealing malware.

  • ROMULUS appears to function as a delivery service rather than being tied to one payload, using separate chains to distribute both CNCMachineRMS and Legion Loader while retaining ClickFix and signed-binary sideloading techniques.
  • The same CNCMachineRMS implant has been delivered through both ROMULUS activity and malicious ChatGPT Custom GPT lures, linking otherwise different victim-entry paths to a common final payload.
  • ClickFix campaigns have expanded beyond simple command execution into multi-stage operations that can establish persistence, support movement within environments, conduct reconnaissance, and steal credentials.
  • Some campaigns combine deceptive verification prompts with unusual delivery methods, including code retrieved through a Polygon smart contract, payloads retrieved through DNS TXT records, and malware reconstructed from data hidden in PNG files.
  • The article notes that changing the applications and loaders used for delivery can obscure campaign tracking, while the underlying malware architecture can provide a more consistent way to identify related activity.

Criminals are using fake verification screens to trick people into copying and running commands on their computers, which installs software that gives the criminals control over the device. The newly identified program can watch a victim’s screen, access the camera and microphone, browse files, and install more harmful software. Windows and Mac users who visit deceptive websites or follow misleading search results, ads, shared links, or phone instructions may be affected. This matters because these scams rely on persuading people rather than breaking into a computer directly, and they are being used in increasingly complex campaigns to steal information and spread further within organizations.
