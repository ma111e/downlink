Hunting Citrix NetScaler Zero-Days with Corelight: Part 2

Corelight shows how Zeek’s existing DTLS analyzer logs can help defenders identify potential Citrix NetScaler zero-day exploitation attempts, including retrospectively in retained historical network traffic.

This follow-up to Corelight’s earlier Citrix NetScaler zero-day hunting article examines a clue recorded by Zeek’s existing DTLS analyzer. It explains how defenders can use that clue within Corelight Open NDR to investigate possible exploitation attempts. The article focuses on network evidence related to candidate NetScaler appliances and DTLS use.

Corelight’s earlier coverage described using its Open Network Detection and Response platform to identify potential NetScaler devices, observe DTLS activity, and search for suspicious behavior. Zeek is an open-source platform maintained by the Zeek Project that produces compact transaction logs, file content, and customizable outputs. Teams that retain the relevant analyzer logs can investigate historical network traffic, including activity recorded before the vulnerability was disclosed.

  • Organizations that retained relevant DTLS analyzer logs can investigate for possible exploitation attempts retroactively, including traffic captured before the vulnerability was publicly disclosed.
  • The investigation relies on a clue from an existing Zeek DTLS analyzer, showing that already collected network records can support a new investigation.
  • Defenders can combine identification of candidate NetScaler appliances with observations of DTLS use to focus their search for suspicious activity.

This article explains how Corelight’s network-monitoring platform can help organizations investigate possible attempts to misuse Citrix NetScaler devices. It focuses on information collected by Zeek, a tool that records details about network connections, including a secure communication method called DTLS. Organizations that kept these records may be able to look back at older network activity—even from before the issue became public—to search for signs of suspicious behavior.
