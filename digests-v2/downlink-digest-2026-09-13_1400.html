Hackers exploit Tencent app flaw to deploy GrayRabbit malware

China-linked UNC3569 is actively exploiting CVE-2026-51990 in Tencent Sogou Input Method for Windows to deploy the GrayRabbit backdoor through a one-click crafted link. Tencent patched the protocol-handler flaw in version 16.3.0.3498, but the app’s outdated, unsandboxed Chromium engine remains a security concern.
KEY POINTS
  • 01Gen Threat Labs reported that UNC3569 is actively exploiting CVE-2026-51990 in Tencent’s Sogou Input Method for Windows to deploy the GrayRabbit backdoor through crafted links.
  • 02The one-click attack abuses Sogou’s sgbiz: link handler to pass attacker-controlled instructions to the application, which then opens an attacker-controlled web page in its embedded browser.
  • 03The malicious page exploits a known flaw in Sogou’s outdated Chromium 80 browser engine, which runs without a sandbox and with key web protections disabled, to execute code and install GrayRabbit.
  • 04GrayRabbit can run programs, provide interactive remote command access, transfer files, collect system and user information, and load additional components into memory.
  • 05Tencent released Sogou Input Method version 16.3.0.3498 on April 21 to restrict protocol-handler URLs, though researchers warned that its underlying browser remains outdated and unsandboxed.

Researchers at Gen Digital say the China-linked UNC3569 group is actively exploiting CVE-2026-51990, a critical one-click remote-code-execution flaw in Tencent’s Sogou Input Method for Windows. The group uses crafted links to deploy the GrayRabbit backdoor. Sogou Input Method is widely used in China, with reportedly hundreds of millions of installations.

The attack abuses Sogou’s sgbiz: link handler to pass unvalidated attacker-controlled arguments to a legitimate program, causing its embedded browser to open an attacker-controlled web page. That page exploits a known weakness in the app’s outdated Chromium 80 engine, which runs without a sandbox and with important web-security protections disabled. GrayRabbit can execute processes, open interactive reverse shells, transfer files, collect system and user details, and load plugins into memory.

Tencent released Sogou Input Method version 16.3.0.3498 on April 21 after Gen Threat Labs reported the issue on April 9. The update validates protocol-handler URL arguments, allows only HTTPS, and limits navigation to approved Sogou and Tencent domains. Researchers cautioned that the underlying browser remains outdated and unsandboxed despite the fix.

  • The reported fix limits which URLs the Sogou protocol handler can open, but researchers said the application still contains an outdated Chromium browser that runs without a sandbox and with multiple web protections disabled.
  • The attack requires only a victim to click a crafted custom link, rather than download and run a separate file first.
  • The analyzed GrayRabbit sample is a more mature 64-bit version with expanded commands and an RC4-encoded command-and-control configuration.
  • Google researchers previously linked UNC3569 to both cybercrime activity and the cyber contractor-for-hire ecosystem.

A China-linked hacking group has used a flaw in Tencent’s Sogou Input Method for Windows, a Chinese typing app with hundreds of millions of installations, to install GrayRabbit, a program that can give attackers control over a victim’s computer. The attack can begin when someone clicks a specially made link, which opens the app’s built-in web browser and runs harmful code. Tencent released a fix in version 16.3.0.3498, but researchers say the app still uses an old browser component with weak safety protections, leaving users at continued risk.
