100+ Compromised Websites Use Fake Cloudflare Checks to Deliver LunexStealer

CERT-UA reports that more than 100 compromised websites are using fake Cloudflare verification pages and ClickFix prompts to trick Windows users into installing LunexStealer. The campaign, attributed to UAC-0277, uses blockchain-hosted configuration and can deploy a malicious browser extension capable of stealing credentials, browser data, and files.
KEY POINTS
  • 01CERT-UA identified more than 100 compromised websites injected with malicious JavaScript that serves LunexStealer, and attributed the activity observed in September 2026 to UAC-0277.
  • 02Visitors to affected websites may see a forged Cloudflare verification page that prompts them to run a command, causing a malicious MSI installer to download and install through the ClickFix technique.
  • 03The campaign uses EtherHiding to retrieve the fake-verification resource domain and operating mode from smart contracts on the Polygon or Ethereum network.
  • 04LunexStealer can install the LUNARAXE browser extension, which masquerades as Microsoft Office Word Editor and can steal cookies, browsing history, and credentials entered into web forms.
  • 05CERT-UA recommends restricting access to the Windows Run dialog and user MSI installation, monitoring msiexec.exe, enabling Microsoft’s vulnerable driver blocklist, and allowlisting browser extensions.

CERT-UA identified more than 100 compromised websites injected with malicious JavaScript that delivers LunexStealer, also known as Psychedelic Stealer. The activity, observed in September 2026 and attributed to UAC-0277, presents visitors with a forged Cloudflare verification page. The page prompts users to run a command that downloads and installs a malicious MSI package through the ClickFix technique.

The campaign uses EtherHiding to obtain the fake-page domain and operating mode from Polygon or Ethereum smart contracts. The fake prompt is shown only to Windows users who arrive through search results and no more than twice in 12 hours. Different installer variants can install LunexStealer directly, add Microsoft Defender exclusions and use a vulnerable AMD driver to disable security software, or use DLL sideloading; the malware can also install the LUNARAXE browser extension to steal browser data and credentials and remotely control browser activity.

  • The fake verification page is selectively shown only to Windows users arriving from search results and no more than twice in 12 hours, which limits its visibility compared with showing the lure to every visitor.
  • The campaign’s behavior can be remotely changed between inactive, visitor-tracking, and fake-verification modes through data retrieved from Polygon or Ethereum smart contracts.
  • One installer variant uses a legitimate but vulnerable AMD driver to disable security software after adding Microsoft Defender exclusions, while another uses DLL sideloading to launch the stealer.
  • The LUNARAXE extension can remove website security-policy headers, allowing it to run arbitrary JavaScript on pages, in addition to collecting browser data and entered credentials.
  • CERT-UA’s recommended controls directly target the delivery chain: restrict the Windows Run dialog and non-administrator MSI installation, monitor msiexec.exe, block vulnerable drivers, and allow only approved browser extensions.

Ukraine’s cyber emergency team found more than 100 hacked websites that show visitors a fake Cloudflare “human verification” page and tell them to run a command on their Windows computer. People who follow the prompt can unknowingly install LunexStealer, a program that can steal passwords, browser information, and files. The campaign targets Windows visitors arriving through search results, showing how even trusted-looking websites and familiar security checks can be used to trick people into handing over sensitive data.

This is an active, attributed campaign using more than 100 compromised websites to deliver an information stealer through convincing fake Cloudflare checks. It includes concrete delivery, evasion, browser-extension, and detection details that are broadly useful to defenders, though no confirmed victim compromises are reported.

Anthropic Expands Claude Access for Vetted Cyber Teams as Glasswing Finds 129,000 Flaws

Anthropic expanded vetted cyber teams’ access to Claude models with tiered safeguards, citing Project Glasswing’s discovery of 129,000 verified software flaws. The company says the program supports defenders, though only two of 300 tracked Anthropic-found CVEs have reportedly seen exploitation in the wild.
KEY POINTS
  • 01Anthropic expanded its Cyber Verification Program, which gives vetted cybersecurity organizations tiered access to Claude models with reduced safeguards for approved work.
  • 02Anthropic said Project Glasswing identified at least 129,000 verified software vulnerabilities from April through July 2026, including more than 33,000 rated critical or high severity.
  • 03The program offers Defense Access for activities such as incident response and vulnerability validation, Red Team Access for authorized penetration testing, and Specialized Access for a limited set of organizations testing safety systems.
  • 04In a CyScenarioBench evaluation, Claude Opus 5.5 under Defense Access blocked 46 of 50 tasks, while Red Team Access blocked none and completed 34 of 50 tasks.
  • 05VulnCheck reported that only two of 300 vulnerabilities credited to Anthropic or Project Glasswing had been exploited in the wild: CVE-2026-26980 in Ghost CMS and CVE-2026-61500 in Rejetto HTTP File Server.

Anthropic expanded its Cyber Verification Program (CVP), allowing vetted cybersecurity organizations to access Claude models with reduced safeguards for approved security work. The program has three tiers: Defense Access for tasks such as incident response and software-flaw validation, Red Team Access for authorized penetration testing, and Specialized Access for a limited group authorized to test safety systems. Participants can access Claude Opus 5.5, Claude Sonnet 5.5, Claude Mythos 5.1, and future models.

Anthropic said Project Glasswing found at least 129,000 verified software vulnerabilities between April and July 2026, while open-source scanning found another 5,500 between April and October. More than 33,000 of the verified flaws were rated critical or high severity, although Anthropic said this figure is likely an undercount based on survey data from only some Glasswing partners. In CyScenarioBench testing, Defense Access blocked 46 of 50 tasks on Claude Opus 5.5, whereas Red Team Access blocked none and completed 34 of 50 tasks, matching the result without safeguards.

VulnCheck researcher Patrick Garrity found that only 2 of 300 vulnerabilities credited to Anthropic or Project Glasswing had been exploited in the wild: CVE-2026-26980 in Ghost CMS and CVE-2026-61500 in Rejetto HTTP File Server. The article notes that AI may make it easier to find software flaws, but not every discovered flaw is practically exploitable or causes significant harm. It also cites 1Password and Veracode findings that AI-generated fixes can introduce security risks, with Veracode reporting risky flaws in roughly 44% of AI code-generation tasks tested.

  • Access controls materially changed Claude Opus 5.5’s behavior in testing: Defense Access blocked 46 of 50 tasks, while Red Team Access blocked none and matched the completion rate seen without safeguards.
  • The reported volume of AI-assisted findings did not translate directly into known real-world abuse: VulnCheck found active exploitation for only 2 of 300 vulnerabilities credited to Anthropic or Project Glasswing.
  • Anthropic’s estimate may be incomplete because its 33,000 critical- or high-severity figure comes from survey data from only a subset of Glasswing partners.
  • AI can create security issues while helping find them, as Veracode reported that roughly 44% of AI code-generation tasks introduced a risky security flaw in its tests.

Anthropic is giving approved security teams broader access to its Claude AI tools so they can look for weaknesses in software and help fix them. It says a related effort found at least 129,000 confirmed software flaws, including more than 33,000 rated serious or critical. This matters because the same AI abilities that can help protect organizations could also be misused, and finding many flaws does not mean all of them can be practically used to harm people or systems.

OPEN SOURCE ↗

Anthropic’s expansion of tiered, reduced-safeguard Claude access for vetted cyber teams is a concrete development with broad relevance to security testing and AI safety controls. The Project Glasswing vulnerability figures add context, though the article does not report an urgent patch or widespread active exploitation.

UK Cybercrime Journal: Police Cryptocurrency Crime Operations in 2026

UK law enforcement actions in 2026 show cryptocurrency crime increasingly combines police-impersonation and seed-phrase scams with physical coercion, while unregistered P2P exchanges enable laundering. Crypto holders should protect recovery phrases, independently verify urgent calls, limit public exposure of holdings, and use multisig or time-locked custody to reduce forced-transfer risk.
KEY POINTS
  • 01Three Sheffield teenagers posing as Amazon delivery drivers used violence during a London home invasion and forced a victim to transfer £3.1 million in cryptocurrency.
  • 02A multi-force UK operation arrested and charged ten suspects accused of calling victims while posing as police officers or cryptocurrency-platform representatives to obtain wallet recovery phrases.
  • 03Three men were jailed for defrauding eight victims of more than £4 million in cryptocurrency by impersonating police and directing funds to purported secure police accounts.
  • 04The FCA, HMRC, and Metropolitan Police targeted three London premises alleged to be operating unregistered peer-to-peer cryptocurrency exchanges outside anti-money-laundering and counter-terrorist-financing requirements.
  • 05The article advises cryptocurrency holders never to disclose recovery phrases, independently verify unexpected police or exchange calls, and consider multi-signature and time-locked storage.

UK enforcement actions in 2026 addressed cryptocurrency crime ranging from a violent London home invasion to phone-based fraud and unregistered peer-to-peer trading operations. In one case, three Sheffield teenagers posing as Amazon delivery drivers forced a victim to transfer £3.1 million in cryptocurrency; police detained them within hours and the assets were recovered within 72 hours. Separate multi-force operations arrested alleged fraudsters who posed as police officers or cryptocurrency-platform representatives to obtain wallet recovery phrases, while another group was jailed after stealing more than £4 million from eight victims.

The cases show how criminals combine social engineering with physical coercion, using trusted police branding to make victims reveal recovery phrases or move money to supposed safe accounts. The FCA, HMRC, and Metropolitan Police also targeted three London premises alleged to be operating unregistered peer-to-peer cryptocurrency exchanges outside required anti-money-laundering and counter-terrorist-financing controls. The article advises holders to avoid public disclosure of holdings and locations, never share recovery phrases, verify unexpected calls through official numbers, and consider multi-signature wallets or time-locked storage to limit forced transfers.

  • Police impersonation can defeat ordinary account protections because victims may be pressured into voluntarily revealing wallet recovery phrases or approving transfers.
  • Public social-media posts about wealth, holdings, or location can make cryptocurrency owners easier to identify and target for in-person robbery.
  • Multi-signature wallets and time-locked storage can reduce the immediate ability of criminals to force a cryptocurrency transfer during a physical home invasion.
  • Unregistered peer-to-peer cryptocurrency businesses can provide a route for illicit digital funds to be converted into cash or apparently legitimate bank transfers.
  • The Sheffield suspects' Snapchat posts illustrate that criminals’ public online activity can create an investigative opportunity for law enforcement.

In 2026, UK authorities acted against several cryptocurrency crimes, including a violent home robbery, phone scams where criminals pretended to be police or crypto companies, and unregistered businesses used to turn digital funds into cash. People with cryptocurrency, especially those who publicly display their wealth, can be targeted and pressured or tricked into giving away the secret recovery words that control their money. The cases show that digital theft can lead to real-world harm and that criminals may use poorly regulated trading channels to hide or spend stolen funds.
