Brotli2Shell: Frequently asked questions for Google Brotli decoder vulnerability (CVE-2026-111497)

CVE-2026-111497 (Brotli2Shell) is a critical out-of-bounds write in the Google Brotli decoder that can enable remote code execution when applications decompress attacker-controlled data. Organizations should update affected Brotli-dependent software, including Node.js, .NET, Bun, Envoy, Istio, Python packages, and PHP Windows builds, then restart or redeploy affected workloads.

CVE-2026-111497, also called Brotli2Shell, is an out-of-bounds write flaw in Google’s Brotli C decoder library that Google scored 9.2 under CVSSv4.0. An attacker can trigger it by causing an application to decompress crafted Brotli data, including through compressed HTTP responses or request bodies. The possible impact ranges from application crashes and process-memory disclosure to potential remote code execution, and public proof-of-concept code is available.

The flaw affects software that uses a vulnerable Brotli decoder, including Google Brotli, Node.js, Bun, Envoy Proxy, Istio, supported Microsoft .NET releases, Python Brotli packages, and PHP Windows builds. JFrog research also identified reachable paths in FFmpeg, Apache Arrow, and ClickHouse, while Python HTTP clients may be affected when Brotli or brotlicffi is installed. Fixed releases are available for major affected projects, but embedded Brotli copies require updating the application itself, and patched processes, containers, and scheduled jobs must be restarted or redeployed for the fix to take effect.

  • Updating a system-installed Brotli library alone may not resolve the issue because applications such as Node.js and Bun can ship with their own embedded decoder copy.
  • Removing "br" from an HTTP client’s Accept-Encoding header is not a complete mitigation, because a hostile server can still send Brotli-compressed data.
  • Microsoft states that affected .NET packages alone do not make an application exposed: ASP.NET Core request decompression and HttpClient automatic response decompression are disabled by default.
  • Node.js versions that have reached end of support, including versions 20, 23, and 25, will not receive fixed releases.
  • Patches take effect only after affected processes or scheduled jobs are restarted, and containers must be rebuilt and redeployed.

The article describes a serious flaw, called Brotli2Shell, in software used to unpack Brotli-compressed data. It can affect programs such as Node.js, .NET, Bun, Envoy, Istio, Python web clients, PHP on Windows, FFmpeg, Apache Arrow, and ClickHouse when they open compressed data controlled by an attacker. In the worst case, an attacker could crash a program, view parts of its memory, or take control of it remotely, and public demonstration code is available. Updating affected software and restarting or redeploying it is important because changing only the computer’s shared Brotli component may not fix programs that include their own copy.

OPEN SOURCE ↗

This is a critical, widely relevant vulnerability advisory for a Brotli decoder used by major runtimes, proxies, and libraries including Node.js, .NET, Bun, Envoy, Istio, and Python packages. Public proof-of-concept code is available, and ELLIO reported an observed exploitation attempt, making prompt patching and redeployment highly important.
