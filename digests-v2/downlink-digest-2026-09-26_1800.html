ShinyHunters uses WAF bypass trick in Oracle PeopleSoft attacks

ShinyHunters is bypassing WAF rules that block Oracle PeopleSoft’s vulnerable /PSEMHUB/ endpoint by percent-encoding the “P,” enabling continued exploitation of CVE-2026-35273. Organizations should apply Oracle’s security update rather than rely on path-based WAF blocking and review logs for encoded endpoint requests.
KEY POINTS
  • 01ShinyHunters is using the percent-encoded path /%50SEMHUB/ to bypass web application firewall rules that only block the literal /PSEMHUB/ path on Oracle PeopleSoft servers vulnerable to CVE-2026-35273.
  • 02Oracle fixed CVE-2026-35273 on June 11 and described it as an unauthenticated remote code execution flaw in PeopleSoft.
  • 03Google reported that the renewed campaign has deployed web shells on dozens of systems worldwide across higher education, technology, IT services, healthcare, agriculture, transportation, and government organizations.
  • 04After identifying a vulnerable server, the attackers execute commands in memory or deploy JSP web shells, including x.jsp for command execution and u.jsp or u2.jsp for larger file uploads.
  • 05Mandiant recommends installing the latest security update and reviewing WebLogic access logs for both /PSEMHUB/ and encoded variants such as /%50SEMHUB/.

ShinyHunters is using a URL-encoding technique to bypass web application firewall rules intended to block access to Oracle PeopleSoft’s vulnerable /PSEMHUB/ endpoint. Instead of requesting the literal path, the group sends requests to /%50SEMHUB/, where %50 represents the letter P. Some WAFs and reverse proxies check the path before decoding it, while Oracle WebLogic decodes it and routes the request to the vulnerable endpoint. This can leave servers exposed even when operators believed their WAF rule mitigated CVE-2026-35273.

Google reported that the renewed campaign has deployed web shells on dozens of systems worldwide in higher education, technology, IT services, healthcare, agriculture, transportation, and government. Attackers commonly send five to 15 POST requests containing serialized Java objects to assess whether a system can be exploited quietly, then execute commands in memory or deploy JSP web shells. On compromised systems, the group has used the SIDEEYE backdoor, Neo-reGeorg tunneling toolkit, and MeshAgent remote-management software. Mandiant recommends applying Oracle’s latest security update and reviewing WebLogic logs for both literal and encoded /PSEMHUB/ requests.

  • A WAF rule that appears to block the vulnerable PeopleSoft path can fail because some WAFs compare the request before decoding it, while Oracle WebLogic decodes the path and still sends it to the vulnerable endpoint.
  • ShinyHunters typically sends five to 15 serialized-object requests before attempting full compromise, using the responses to determine whether a server can be exploited without writing files or disrupting service.
  • The group uses separate JSP web shells for command execution and for uploading larger files, then can use Neo-reGeorg to turn a compromised PeopleSoft server into a route into an organization’s internal network.
  • Searching logs only for the literal /PSEMHUB/ path may miss evidence of compromise; Mandiant specifically advises checking for encoded forms such as /%50SEMHUB/ as well.

The ShinyHunters extortion group found a way around a common website security block protecting Oracle PeopleSoft servers, letting it keep breaking into unpatched systems and stealing data. The group has reportedly placed remote-control tools on dozens of affected organizations worldwide, including schools, technology companies, healthcare providers, transportation organizations, and government bodies. This matters because organizations that thought a simple website rule protected them may still be exposed, and compromised servers can be used to reach other systems inside an organization.

Lunex Stealer Abuses AMD Driver to Disable Security Monitoring and Steal Browser Credentials

Lunex, a malware-as-a-service platform targeting Ukrainian users through ClickFix lures on compromised websites, uses a vulnerable AMD driver to quietly disable security monitoring before deploying its Psychedelic Stealer payload. The malware steals browser credentials and cryptocurrency-wallet data, adds persistence, and can maintain remote filesystem control through Chrome Native Messaging.
KEY POINTS
  • 01Lunex is a malware-as-a-service platform whose Psychedelic Stealer component was delivered through ClickFix-style fake Cloudflare verification pages on compromised Ukrainian websites.
  • 02The infection chain uses bogus MSI installers and LunexLoader to bypass Windows User Account Control, load the vulnerable AMD Radeon Software driver PDFWKRNL.sys, and disable security monitoring before downloading the stealer.
  • 03LunexStealer steals credentials from seven Chromium-based browsers and collects data from desktop and browser-extension cryptocurrency wallets.
  • 04The malware establishes persistence through a Registry Run key, a hidden scheduled task named psychedelicloveUtils, and a Chrome Native Messaging Host backed by an embedded PowerShell script.
  • 05Ontinue identified 28 Lunex panels across 13 countries and reported that the panel analysis points to a Russian-speaking developer or development team.

Lunex is a malware-as-a-service platform linked to Psychedelic Stealer, which was distributed through compromised Ukrainian websites using fake Cloudflare verification pages designed to trick users into running bogus MSI installers. Ontinue described a four-stage attack chain targeting Ukrainian-speaking users that culminates in a command-and-control agent capable of stealing browser and cryptocurrency-wallet data. LunexLoader bypasses Windows User Account Control through the CMSTPLUA COM object, loads a vulnerable AMD Radeon Software driver, and then downloads the information-stealing payload.

The campaign abuses the AMD PDFWKRNL.sys kernel driver affected by CVE-2023-20598 to raise privileges and disable security monitoring while leaving security processes running. LunexStealer targets credentials in Chrome, Edge, Brave, Yandex Browser, Opera, Opera GX, and Vivaldi, and it can collect data from several desktop and browser-extension cryptocurrency wallets. It also persists through a Registry Run key, a hidden scheduled task, and a Chrome Native Messaging Host that can read, write, download, and execute files; Ontinue identified 28 Lunex panels across 13 countries and said the panel analysis points to a Russian-speaking developer or team.

  • Lunex uses the AMD PDFWKRNL.sys driver to leave security products running while preventing them from monitoring activity, rather than visibly terminating those products.
  • Ontinue reported that the specific PDFWKRNL.sys variant could still load despite HVCI and Microsoft’s Vulnerable Driver Blocklist, even though its hash had been catalogued by LOLDrivers.
  • Its Chrome Native Messaging Host remains available after the stealer binary is deleted, the system restarts, or Chrome restarts, and can list drives, read and write files, download files, and run programs.
  • The Lunex platform appears to extend beyond information theft: one Turkey-hosted panel resolved to five phishing domains associated with brand impersonation.
  • The number of identified Lunex command-and-control panels grew from six in June 2026 to 28 across 13 countries, indicating rapid expansion of the platform.

Criminals are using hacked Ukrainian websites to show fake verification pages that trick visitors into installing harmful software called Lunex. It can turn off security monitoring without visibly closing security programs, then steal saved browser passwords, login sessions, and cryptocurrency wallet information. It can also remain on the computer after restarts and give criminals continued access to files and programs. The campaign’s growth across many countries suggests the service may be available to multiple criminal groups, increasing the risk of account theft and financial loss.

OPEN SOURCE ↗

This is an active, technically significant malware campaign that uses compromised websites, ClickFix lures, UAC bypass, and a vulnerable AMD driver to blind security monitoring before stealing credentials and cryptocurrency-wallet data. The reported failure of HVCI and Microsoft’s Vulnerable Driver Blocklist to stop the specific driver variant makes the findings broadly relevant to Windows defenders.
