BdThemes plugins supply-chain hack creates rogue WordPress admins

BdThemes’ WordPress plugin ecosystem was hit by a supply-chain compromise where attackers poisoned a remote JSON feed to run malicious JavaScript in admin dashboards, creating hidden rogue administrator accounts. Affected plugins were pulled from WordPress.org while the issue remained under investigation.
KEY POINTS
  • 01A threat actor compromised BdThemes’ upstream infrastructure and modified a remote JSON feed delivered to administrators’ browsers to create rogue WordPress administrator accounts.
  • 02Wordfence researchers said the attacker poisoned a static remote JSON data stream after obtaining write access to the vendor’s storage bucket, exploiting a cross-site scripting flaw in the Biggop Library used by the Biggopti component.
  • 03The malicious JavaScript used a legitimate administrator’s authenticated session to create rogue admin accounts, and an additional payload called w2.js established persistence through a webshell named emer-run.php by installing a fake plugin.
  • 04The affected BdThemes plugins were pulled from the WordPress.org directory on August 8 pending investigation, and the issue was listed as unpatched as of publication.
  • 05Defiant said the earliest possible start of the campaign was June 23, while Wordfence began seeing attacks through its web application firewall on August 7.

A threat actor compromised the upstream infrastructure of BdThemes, a developer of premium WordPress web-design tools, and modified a remote JSON feed delivered to administrators’ browsers to create rogue admin accounts. BdThemes provides plugins including Element Pack, Prime Slider, Ultimate Post Kit, Pixel Gallery, and Ultimate Store Kit. Its free Element Pack plugin shows more than 100,000 active installations on WordPress.org, while BdThemes advertises more than 350,000 active installs across its portfolio.

Defiant said Wordfence began seeing attacks through its web application firewall on August 7, and researchers determined the earliest possible start of the campaign was June 23. The affected BdThemes products were pulled from the WordPress.org directory on August 8 pending investigation, and the article says the issue was listed as unpatched as of publication. At the time of writing, BdThemes had not published an official statement, and BleepingComputer had not received a response to its request for comment.

Researchers said the attacker poisoned a static remote JSON data stream after obtaining write access to the vendor’s storage bucket. The attack exploited a cross-site scripting flaw in the Biggop Library used by the Biggopti component, allowing malicious JavaScript to run when a logged-in administrator opened a wp-admin page. The injected code used the legitimate administrator’s authenticated session to create rogue admin accounts, manipulated WordPress database queries to hide them, and used an additional payload called w2.js to establish persistence through a webshell named emer-run.php by installing a fake plugin.

  • The compromise was especially stealthy because it was driven entirely through a remote API response and did not require a plugin update, file modification, or user interaction.
  • The malicious code executed whenever a logged-in administrator opened a WordPress admin page, meaning routine site management activity could trigger the compromise.
  • The injected code manipulated WordPress database queries to hide rogue administrator accounts from the user list, reducing the chance that site owners would notice the compromise through normal admin checks.
  • Although the issue was assigned only a medium severity score, the article describes an attack path that could create persistent hidden administrator access on impacted sites.
  • Defiant said reports on the command-and-control infrastructure linked the observed attacks to the same attacker associated with recent Advanced Responsive Video Embedder and OptinMonster supply-chain compromises.

Hackers compromised infrastructure used by BdThemes, a maker of popular WordPress site-design plugins, and changed a remote data file so that when website owners opened their WordPress admin pages, hidden administrator accounts could be created on their sites. The affected products include Element Pack, Prime Slider, Ultimate Post Kit, Pixel Gallery, and Ultimate Store Kit, with Element Pack alone used on more than 100,000 sites and BdThemes advertising over 350,000 active installs. This matters because the attack did not require a site owner to install an update or click anything, and the malicious code also tried to hide the new administrator accounts, making affected websites harder to clean up or even notice as compromised.

OpenAI releases ChatGPT 5.6 Cyber, but it's only for approved users

OpenAI has launched GPT 5.6 Cyber, a specialized model for vulnerability research, penetration testing, incident response, and remediation, but access is limited to approved security partners and vendors. Customers will use it through those partners’ services rather than receiving direct access to the underlying model.
KEY POINTS
  • 01OpenAI has developed GPT 5.6 Cyber, a model designed for vulnerability research, penetration testing, and incident response.
  • 02GPT 5.6 Cyber is available only to select companies and supported security vendors, not to regular users.
  • 03OpenAI says approved partners will use the models inside existing security products, managed services, and customer engagements rather than transferring access directly to customers.
  • 04OpenAI offers Daybreak Blue for broad defensive security workloads and Daybreak Red for more specialized and closely governed work.
  • 05OpenAI says safeguards may include identity verification, clearly defined testing scopes, logging, monitoring, and human oversight.

OpenAI has developed a new model called GPT 5.6 Cyber for vulnerability research, penetration testing, and incident response. The model is only available to select companies, including Accenture, IBM, Capgemini, Cognizant, EY, KPMG, PwC, NCC Group, and SpecterOps. It is also rolling out to supported security vendors, including Palo Alto Networks, CrowdStrike, Cisco, Sophos, Akamai, Fortinet, and Cloudflare.

OpenAI says regular users will not receive access to the underlying models because of security risks and past abuse of models to launch security attacks. Approved partners will instead use the models inside existing security products, managed services, and customer engagements. OpenAI says this approach can help defenders find serious vulnerabilities, validate which ones matter, and fix them faster.

Partners can access two versions of ChatGPT’s cyber capabilities through Daybreak Access: Daybreak Blue and Daybreak Red. Daybreak Blue is designed for broad defensive security workloads, while Daybreak Red is intended for more specialized and closely governed work. OpenAI says safeguards may include identity verification, clearly defined testing scopes, logging, monitoring, and human oversight, and that access to the underlying models remains with the approved partner rather than being transferred directly to the customer.

  • OpenAI is using a partner-controlled delivery model in which customers can benefit from GPT 5.6 Cyber during engagements without receiving direct access to the underlying models.
  • The split between Daybreak Blue and Daybreak Red shows that OpenAI is separating general defensive uses from more sensitive security work that requires closer governance.
  • The approved partner list combines major consulting firms with security product vendors, indicating the model is intended for both managed service engagements and integration into existing security products.
  • OpenAI’s stated safeguards, including identity verification, defined testing scopes, logging, monitoring, and human oversight, show that access is being treated as a controlled security workflow rather than a general-purpose ChatGPT feature.

OpenAI has created GPT 5.6 Cyber, a new ChatGPT model meant to help find and fix security weaknesses, investigate incidents, and test whether problems can really be used by attackers. It is not available to regular users because OpenAI says such models can be misused, so only approved companies and security vendors like Accenture, IBM, CrowdStrike, Cisco, Fortinet, and Cloudflare can use it inside their own services. This matters because businesses may get access to stronger AI help for fixing serious security problems faster, while OpenAI is trying to limit the risk that the same tools could be used to cause harm.

FBI, South Korea warn of Gunra ransomware gang targeting critical infrastructure

The FBI and South Korea warned that the Gunra ransomware gang is exploiting Fortinet firewall vulnerabilities to target critical infrastructure, healthcare, finance and government organizations worldwide. Victims face data theft, encryption and ransom demands often exceeding $10 million.
KEY POINTS
  • 01The FBI and South Korea’s National Police Agency warned that the Gunra ransomware gang is exploiting Fortinet firewall vulnerabilities CVE-2024-55591 and CVE-2025-24472 to breach critical infrastructure organizations.
  • 02The advisory said Gunra emerged in April 2025 and was built using source code from the Conti ransomware that was leaked in 2022.
  • 03The agencies said Gunra is targeting healthcare, financial services and government sectors globally, with ransom demands in many cases exceeding $10 million and payment deadlines of five to seven days.
  • 04Researchers recently warned that some tools and infrastructure used by North Korea’s Lazarus Group appear to have been shared with Gunra as it targeted South Korean organizations.
  • 05The advisory noted that researchers found a weakness in Gunra’s Linux variant that can allow defenders to reconstruct keys using file timestamps and recover files without paying the ransom.

The FBI and South Korea’s National Police Agency warned that the Gunra ransomware gang is breaching critical infrastructure organizations through vulnerabilities in popular Fortinet firewall products. The joint advisory said Gunra actors have been exploiting CVE-2024-55591 and CVE-2025-24472 to gain privileged access, steal data, encrypt systems and extort victims. The agencies said the group is targeting healthcare, financial services and government sectors globally.

Gunra emerged in April 2025 and is built using source code from the Conti ransomware that was leaked in 2022. In many incidents reviewed by the FBI and South Korea’s police agency, victims received ransom demands exceeding $10 million and were given five to seven days to pay. The FBI also observed Gunra actors trying to contact management staff at victim companies directly by email to solicit ransom payments, with limited success.

The FBI said Gunra has expanded and commercialized its platform, moved to a ransomware-as-a-service model and recruited hackers to act as initial access brokers under aliases including “Golden Community.” The group initially focused on Windows devices but later created a Linux variant, which researchers found has a weakness that can allow defenders to reconstruct keys from file timestamps and recover files without paying. The advisory comes as Dragos reported 1,140 ransomware incidents affecting industrial organizations worldwide in the second quarter of 2026, including four attributed to Gunra.

  • Gunra’s use of leaked Conti source code shows that older ransomware leaks can continue to enable new groups years later, with this operation emerging in April 2025 from code leaked in 2022.
  • Gunra’s Linux variant may not always require ransom payment for recovery because researchers found that defenders can reconstruct keys from file timestamps.
  • Gunra’s move to a ransomware-as-a-service model and recruitment of initial access brokers indicates the group has shifted from a single operation toward a broader criminal platform.
  • The group’s attempts to email victim-company management directly show that its extortion tactics extend beyond technical disruption into pressure on business leadership.

The FBI and South Korea warned that a criminal group called Gunra is breaking into organizations by abusing flaws in widely used Fortinet firewall products, then stealing and locking their data to demand payment. The group is targeting healthcare, financial services, government and other critical infrastructure organizations around the world, with some ransom demands over $10 million. This matters because attacks on these kinds of organizations can disrupt essential services and cause serious harm to people and businesses.
