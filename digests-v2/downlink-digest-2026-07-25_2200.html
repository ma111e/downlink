Steam forum ClickFix attacks infect gamers with XMRig cryptominers

Attackers are abusing Steam discussion forums with fake “fixes” that tell users to run PowerShell commands, which secretly install the XMRig cryptominer with persistence and Microsoft Defender exclusions. Users should not run forum-provided commands and should check for the C:\Windows\Background folder, XMRig scheduled tasks, and Defender exclusions if they did.
KEY POINTS
  • 01Threat actors are creating random Steam accounts to post replies that appear to offer fixes for game crashes, lost inventory items, and other technical issues.
  • 02The malicious replies instruct users to open PowerShell as an administrator and run a command that quietly downloads and launches an XMRig miner executable.
  • 03The PowerShell script masquerades as a Windows optimization utility named "msf utility \\ PC Opt" and displays fake maintenance progress messages to appear legitimate.
  • 04When run with administrator privileges, the script creates C:\Windows\Background, adds that path as a Microsoft Defender exclusion, downloads a payload from msfconfig[.]icu, and installs it as C:\Windows\Background\system.exe.
  • 05The malware creates a scheduled task named "XMRig-[computer name]" to launch system.exe with SYSTEM privileges every time Windows starts.

Steam discussion forums are being abused in ClickFix attacks that present malicious PowerShell commands as fixes for game and computer problems. Threat actors are creating random Steam accounts and replying to posts about issues such as games crashing, lost inventory items, and technical problems. The replies tell users to open PowerShell as an administrator and run a command that quietly downloads and launches an XMRig miner executable.

The PowerShell script masquerades as a Windows optimization utility named “msf utility \ PC Opt” and displays messages claiming to perform maintenance tasks such as cleaning temporary files, flushing the DNS cache, updating drivers, scanning for malware, and repairing Windows. The article says most of these functions do not perform the tasks they claim, but instead show fake progress messages and pause for random periods to appear legitimate. The malicious activity is hidden in a function named “Advanced-Optimization,” which requires administrator privileges before continuing.

When run with elevated privileges, the script creates the C:\Windows\Background directory and adds it as an exclusion to Microsoft Defender scanning. It downloads the XMRig miner payload from msfconfig[.]icu, installs it as C:\Windows\Background\system.exe, and creates a scheduled task named “XMRig-[computer name]” to run it with SYSTEM privileges at Windows startup. The article advises users not to run PowerShell commands from unknown forum users and says anyone who executed the command should check for the directory, Defender exclusion, and scheduled task, then remove the miner or consider reinstalling the operating system.

  • The campaign targets users at the moment they are seeking help for an existing problem, which makes the malicious PowerShell command appear like a relevant fix rather than an unsolicited download.
  • Because victims manually run the command, the article notes that the attack can bypass some security protections that might otherwise block automatically executed malicious code.
  • The script removes or stops existing XMRig-related tasks, processes, and configuration files before installing its own miner, though the article says it is unclear whether this is meant to clean up a previous version of the same malware or another miner.
  • The article gives specific compromise checks for affected users: look for C:\Windows\Background, a Microsoft Defender exclusion for that path, and a scheduled task beginning with XMRig-.
  • The article warns that reinstalling the operating system may be safer because there is no way to know whether the downloaded payload performed additional malicious actions while it was running.

Attackers are posting fake helpful replies on Steam discussion forums, telling people with game or computer problems to run a Windows PowerShell command that secretly installs software to mine cryptocurrency on their computer. The people affected are Steam users who follow these forum instructions, especially if they run the command as an administrator. This matters because the unwanted program is set up to start every time Windows starts and can hide from Microsoft Defender, using the victim’s computer resources without permission. Anyone who ran the command should look for the signs named in the article and may need antivirus cleanup or even a full Windows reinstall.

It is broadly relevant because it shows a concrete ClickFix tactic on a major platform, though the impact is limited compared with a major breach or critical enterprise vulnerability.
