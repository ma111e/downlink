Hackers breach TrueConf to trojanize client installers with backdoors

Hackers from the Head Mare group are exploiting unpatched TrueConf servers to replace legitimate client installers with trojanized versions that install backdoors. Organizations using or connecting to TrueConf servers should patch immediately and verify installers are legitimate and digitally signed.
KEY POINTS
  • 01The Head Mare hacktivist group has been exploiting vulnerabilities in unpatched TrueConf video conferencing servers to replace client installers with malicious versions that deliver backdoors.
  • 02Kaspersky said the attackers used TCP port 4307 to connect to target TrueConf servers without authentication, then exploited flaws tracked as KLCERT-26-057 and KLCERT-26-058 to execute code, escape the sandbox, and run commands on the operating system.
  • 03After gaining NT AUTHORITY\SYSTEM privileges, the attackers replaced the public\js\locale.php file with a web shell for persistent remote access to the compromised server.
  • 04Compromised TrueConf servers delivered non-digitally signed trojanized TrueConf Client installers containing the PhantomCore backdoor to organization members connecting for updates.
  • 05Head Mare also deployed the PhantomGraph backdoor, which uses a Microsoft OneDrive account to receive commands, return results, dump LSASS memory, run reconnaissance commands, and start a reverse SSH tunnel.

The Head Mare hacktivist group has been exploiting vulnerabilities in unpatched TrueConf video conferencing servers to replace legitimate client installers with malicious versions. Kaspersky discovered the activity in July and reported that the attackers deployed the PhantomCore and PhantomGraph backdoors. TrueConf is widely used in Russia, especially in enterprise and government sectors, as an on-premise alternative to Western video conferencing tools.

Kaspersky said the attackers used TCP port 4307, which is open by default, to connect to TrueConf servers without authentication. They exploited flaws tracked by Kaspersky as KLCERT-26-057 and KLCERT-26-058 to run code, escape TrueConf’s isolated environment, gain NT AUTHORITY\SYSTEM privileges, and install a web shell by replacing the public\js\locale.php file. The web shell was used to collect sensitive information, access the TrueConf database, and replace the hosted TrueConf Client installer with a trojanized, non-digitally signed version containing PhantomCore.

The article says affected users can receive the malicious installer when connecting to a local TrueConf server for an update, and Kaspersky warned that employees may also be exposed when connecting to compromised counterparty TrueConf servers for meetings. Head Mare also deployed PhantomGraph, which uses a Microsoft OneDrive account to receive commands, return results, dump LSASS memory, run reconnaissance commands, and start a reverse SSH tunnel. The exploited flaws affect TrueConf Server 5.3.x before 5.3.9, 5.4.x before 5.4.9, 5.5.x before 5.5.5, and older versions, with fixes released on June 18.

  • Organizations can be exposed even if they do not run TrueConf themselves, because employees may download infected installers when joining meetings hosted on a compromised counterparty TrueConf server.
  • The malicious TrueConf Client installers observed in the campaign were not digitally signed, making installer signature verification a concrete way to spot suspicious updates.
  • The exploited flaws affect multiple supported TrueConf Server branches and were fixed in versions 5.3.9, 5.4.9, and 5.5.5 released on June 18, giving administrators specific minimum versions to check against.
  • The campaign combines server compromise with software update tampering, meaning a breached collaboration server can become a distribution point for infecting many users inside or connected to an organization.

Hackers broke into unpatched TrueConf video meeting servers and swapped the normal client download with a harmful version that secretly gives them access to computers. This mainly affects organizations using TrueConf, which is common in Russia’s business and government sectors, but even people joining meetings on a compromised partner’s server could download the infected software. The stakes are serious because the attackers can steal sensitive information, access stored TrueConf data, and try to steal login details from affected systems.
