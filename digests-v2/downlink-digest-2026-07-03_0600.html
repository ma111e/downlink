PamStealer Uses Fake Maccy Sites and PAM Checks to Steal Mac Login Passwords

Researchers found a new macOS infostealer, PamStealer, spread through fake Maccy websites that tricks users into running a malicious AppleScript and then steals passwords, browser data, crypto wallet data, iCloud Keychain content, and clipboard contents. Its key tactic is validating the victim’s macOS login password locally through PAM before exfiltrating data, making the credential theft more reliable and stealthy.
KEY POINTS
  • 01Jamf Threat Labs discovered a new macOS information stealer called PamStealer that is distributed as a compiled AppleScript file impersonating the legitimate open-source clipboard manager Maccy.
  • 02PamStealer is delivered through a lookalike website, maccyapp.com, that mimics the official Maccy website at maccy.app.
  • 03The malware uses a two-stage chain in which an AppleScript inside a disk image downloads a Rust-based information stealer capable of credential theft, browser data collection, persistence, and exfiltration.
  • 04The AppleScript dropper only continues after fingerprinting the host, including CPU architecture, locale, keyboard layout, and time zone, and it avoids Intel-based Macs, sandboxed or analysis environments, and systems associated with several Eastern European countries.
  • 05The Rust payload steals data from web browsers, cryptocurrency wallet extensions, iCloud Keychain, and clipboard content, and it uses a native password prompt to capture and validate the victim’s macOS login password through the PAM API.

Cybersecurity researchers at Jamf Threat Labs have identified a new macOS information stealer called PamStealer. The malware is distributed as a compiled AppleScript file that impersonates Maccy, a legitimate open-source clipboard manager. It is delivered through a lookalike website, maccyapp[.]com, that mimics the official Maccy site, maccy[.]app.

PamStealer uses a two-stage infection chain in which an AppleScript inside a disk image downloads a Rust-based second-stage payload. The AppleScript includes environment checks and only continues after fingerprinting the host, including CPU architecture, locale, keyboard layout, and time zone. It avoids Intel-based Macs, sandboxed or analysis environments, and systems whose regional settings resolve to several Eastern European countries.

The Rust-based payload can steal data from web browsers, cryptocurrency wallet extensions, iCloud Keychain, and clipboard content, and it exfiltrates encrypted data to attacker-controlled infrastructure. It also shows a native password prompt to capture the victim’s macOS login password and validates the entered password through the PAM API, repeating the prompt until the correct password is supplied. After stealing the password and setting up persistence, it displays a fake message claiming Maccy is damaged and should be moved to the Trash.

  • PamStealer’s AppleScript can still run while carrying the com.apple.quarantine attribute, making its Script Editor-based execution chain attractive as Apple tightens Gatekeeper and Terminal controls.
  • The lure hides its malicious logic below a large block of empty lines and instructs victims to run the script manually with Command-R or the Script Editor Run button, turning a normal user action into the trigger for infection.
  • PamStealer derives a decryption key from local system traits, so the encrypted configuration only unlocks on targeted environments and fails on Intel-based Macs or disallowed regional settings.
  • The stealer does not merely ask for the victim’s Mac password once; it validates the entered password locally through PAM and repeatedly prompts until the correct password is supplied.
  • After stealing the password and registering persistence, PamStealer displays a fake “Maccy is damaged” message to make the victim believe the download was broken and discard the lure.

Researchers found a new Mac password-stealing program called PamStealer that is being spread through fake websites pretending to offer Maccy, a real clipboard app. People who download and run the fake app can be tricked into entering their Mac login password, which the program checks until it is correct, then it can steal browser data, cryptocurrency wallet information, iCloud Keychain data, and clipboard contents. This matters because the fake app copies normal Mac messages and avoids some security checks, so victims may think the download was simply broken after their information has already been stolen.

The article describes a method for finding convincing fake sites that impersonate Gmail. It says this is difficult because many legitimate and benign sites use the word “gmail.” The main idea is to use a multi-layered query that combines several data points to filter out noise.

  • The example shows that favicon reuse can help identify high-fidelity phishing pages even when many benign sites share similar brand-related wording.

The article explains a way to find fake websites pretending to be Gmail by checking for sites that use Gmail’s small website icon and the word “gmail,” while leaving out real Google-owned sites.
