New VOLTA Infostealer Uses Claude, Gemini, and Kimi AI to Rank Victims by Financial Value

Researchers uncovered VOLTA-AUTODOXER, a Windows infostealer that uses Claude, Kimi, or Gemini through OpenRouter to turn stolen credentials and personal data into ranked, monetization-focused victim dossiers. The malware exfiltrates data and AI-generated assessments via Telegram, illustrating how criminals are using LLMs to automate victim triage.
KEY POINTS
  • 01Cisco Talos identified VOLTA-AUTODOXER, a Windows information-stealing program that collects browser credentials and cookies, payment cards, cryptocurrency wallet phrases, application sessions, cloud and SSH keys, Wi-Fi profiles, and screenshots.
  • 02VOLTA creates a structured profile containing information such as location, home address, employer, payment-card last four digits, Slack workspaces, document metadata, iPhone backup indicators, and Roblox account value.
  • 03The malware uses stolen Gmail session access to search for receipts from services including Amazon, DoorDash, Uber Eats, Grubhub, Walmart, and PayPal to support home-address information.
  • 04VOLTA sends collected data to AI models through OpenRouter, defaulting to Claude Opus 4.6 and falling back to Kimi K2 or Gemini 2.5 Flash if a model refuses the request.
  • 05The AI-generated output ranks valuables by potential monetization and assesses the victim's security habits, while VOLTA sends data and analysis results to Telegram at multiple stages.

Cisco Talos researchers identified VOLTA-AUTODOXER, a Windows information stealer that collects browser passwords and cookies, payment-card data, cryptocurrency wallet phrases, application sessions, cloud and SSH keys, Wi-Fi profiles, and screenshots. It also assembles a structured profile of the person using the computer, including possible location and address, employer information, Slack workspaces, document metadata, and indicators of iPhone backups. VOLTA can use stolen Gmail sessions to search receipts and order histories from services such as Amazon, DoorDash, Uber Eats, Grubhub, Walmart, and PayPal to corroborate address information.

The malware sends this evidence bundle through OpenRouter for AI analysis, using Claude Opus 4.6 by default and falling back to Kimi K2 or Gemini 2.5 Flash if a model refuses. Its AI prompt directs the model to rank a victim’s valuables by potential monetization and assess their security practices and password hygiene, turning raw stolen information into a prioritized dossier. VOLTA exfiltrates collected data, AI results, and later enrichment data through Telegram, and its build-time configuration template may indicate either a malware builder offered to customers or custom binaries compiled for individual orders.

  • VOLTA is designed to continue its AI analysis if one model refuses by checking responses for refusal phrases and trying up to two additional models.
  • The malware does more than collect local data: it uses stolen Gmail access to find purchase receipts and order histories that can corroborate a victim's home address.
  • Its build-time template includes slots for Telegram channels, API keys, and settings, a design Talos said suggests either a customer-facing builder kit or custom binaries produced per order.
  • The article highlights that the primary AI advantage is reducing the criminal operator's manual analysis work by converting raw stolen data into prioritized, citation-backed target assessments.
  • Talos described NIK C2 as able to use a victim's OpenAI API key from environment variables, allowing the attacker to run AI analysis using the victim's account and computing charges.

Researchers found a Windows program called VOLTA that steals information such as saved passwords, payment-card details, cryptocurrency wallet phrases, email access, and account sessions. It then sends the stolen details to AI services including Claude, Kimi, or Gemini, which help criminals identify which victims and accounts may be most profitable. People whose computers are infected can have their personal, financial, workplace, and online-account information collected and sent to criminals through Telegram. This matters because AI can reduce the time and skill criminals need to sort through stolen data and choose high-value targets.
