Attackers Chain Three Ivanti Connect Secure Flaws to Gain Unauthenticated Root Access

CISA added two Ivanti Connect Secure flaws to its Known Exploited Vulnerabilities catalog after attackers chained them with an authentication bypass to obtain unauthenticated root-level code execution. Organizations should update ICS to 25.1.1.3 or 22.8R2.6 immediately.
KEY POINTS
  • 01CISA added CVE-2026-111357 and CVE-2026-118527, two Ivanti Connect Secure flaws under active exploitation, to its Known Exploited Vulnerabilities catalog.
  • 02Threat actor UTA0576 chained those two flaws with the authentication-bypass issue CVE-2026-104935 to achieve unauthenticated root-level code execution on Ivanti Connect Secure.
  • 03Rather than deploying web shells or malware, UTA0576 was observed extracting credentials and limited Active Directory metadata, conducting host reconnaissance, and searching for administrator passwords and BitLocker recovery keys.
  • 04Ivanti released fixes in Ivanti Connect Secure 25.1.1.3 and 22.8R2.6, which address all vulnerabilities exploited in the chain.
  • 05Federal Civilian Executive Branch agencies must remediate CVE-2026-111357 by November 2, 2026, and CVE-2026-118527 by November 13, 2026.

CISA added CVE-2026-111357 and CVE-2026-118527, two Ivanti Connect Secure vulnerabilities under active exploitation, to its Known Exploited Vulnerabilities catalog. The flaws were used as part of an exploit chain previously documented by Volexity and attributed to a threat actor tracked as UTA0576. CISA had already added the third flaw in the chain, CVE-2026-104935, to the catalog on October 13, 2026.

The chain combined an authentication bypass, remote code execution, and privilege escalation to give attackers root-level code execution without authentication. UTA0576 was observed extracting credentials and limited Active Directory metadata, conducting host reconnaissance, and searching for administrator passwords and BitLocker recovery keys instead of deploying web shells or malware. Ivanti released fixes in Connect Secure versions 25.1.1.3 and 22.8R2.6, which address all vulnerabilities exploited in the chain.

  • Although CVE-2026-111357 and CVE-2026-118527 individually require authenticated access or local access, attackers combined them with CVE-2026-104935 to gain root-level control without authentication.
  • The observed activity focused on collecting credentials, administrator passwords, BitLocker recovery keys, and Active Directory information rather than deploying web shells or malware.
  • Ivanti said a fix for CVE-2026-104935 was already in quality assurance when exploitation was discovered, so it prioritized releasing that fix before completing disclosure and fixes for the associated privilege-escalation issue.
  • The current Ivanti Connect Secure updates address all flaws used in the reported exploit chain, making upgrades to 25.1.1.3 or 22.8R2.6 the complete remediation described in the article.

Attackers have been actively using three flaws in Ivanti Connect Secure, a product used to provide secure access to computer networks, to take full control of affected systems without needing to log in. The attackers then searched for passwords, BitLocker recovery keys, and limited information from Microsoft Active Directory, which stores details about users and computers. Ivanti has released fixes, and CISA has added two of the flaws to its list of security issues known to be used in real attacks, underscoring the need for affected organizations to install the updates quickly.
