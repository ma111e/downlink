BragJack attacks hijack AI browser agents through malicious extensions

Researchers demonstrated BragJack, a technique in which a malicious Chromium extension can hijack built-in AI browser agents and abuse their privileges to read sensitive data or act on a user’s behalf. Google and Microsoft have patched assigned flaws, but the findings affect multiple AI-enabled browsers and underscore the risks of installing broad-permission extensions.
KEY POINTS
  • 01Security researcher Gal Weizman disclosed BragJack, a proof-of-concept technique that uses one malicious browser extension to hijack AI assistants in five Chromium-based browsers or browser assistants.
  • 02The attack requires the malicious extension to already be installed, after which it can operate without user interaction and abuse the AI agent’s existing privileges to access sensitive information or act on the victim’s behalf.
  • 03The technique uses Chromium’s declarativeNetRequest capability to manipulate network traffic and pages trusted by privileged browser AI components.
  • 04Weizman demonstrated that compromised agents could access browsing history, screenshots, local files, and web content, while the Perplexity Comet agent was forced to summarize a victim’s emails and send the results to another address.
  • 05Google assigned CVE-2026-0628 to the Chrome issue and Microsoft assigned CVE-2026-55945 to an Edge race condition, and both vendors have resolved their assigned flaws.

Security researcher Gal Weizman of Forever Security disclosed BragJack, a proof-of-concept technique that uses a malicious browser extension to hijack AI assistants in Google Chrome, Perplexity Comet, Microsoft Edge, Opera Neon, and Claude for Chrome. The extension must already be installed, but can then operate without user interaction and use the AI agent’s existing privileges to access sensitive information or act for the victim. The research earned more than $20,000 in bug bounties and resulted in two CVEs, with Google and Microsoft resolving the flaws assigned to them.

BragJack uses Chromium’s declarativeNetRequest feature to alter web requests and pages trusted by privileged browser components that carry out AI-directed actions. In demonstrations, the resulting access could include local files, browsing history, screenshots, web content, and potentially a browser’s camera and microphone; the Comet agent was also forced to summarize a victim’s emails and send the results elsewhere. Weizman calls the approach Prompt Forcing because it provides an agent with complete prompts and follow-up instructions rather than placing malicious instructions inside content the AI reads. The findings show how an extension that traditionally accesses web content can become a route to AI features able to read data and act on websites for a user.

  • BragJack does not rely on hiding instructions inside content an AI happens to read; it can supply the agent with a complete prompt and follow-up instructions, a method the researcher calls Prompt Forcing.
  • Chromium’s declarativeNetRequest feature allowed the same malicious extension to be used across all five targets by altering request handling, including security headers and resource redirects.
  • Chrome blocked extensions from directly accessing its privileged AI component and injecting scripts into Gemini, but intercepting requests from the embedded Gemini web app still provided a route to execute code in its context.
  • In Perplexity Comet, a testing domain that lacked the main Perplexity site’s protections created a trust path to the built-in agent, while Edge’s separation of planning and action modes was bypassed through a timing flaw.

A researcher showed that one harmful browser add-on can take over the AI helpers built into Chrome, Edge, Perplexity Comet, Opera Neon, and Claude for Chrome. Once installed, it may be able to make these helpers read files, view browsing information or email, take screenshots, and perform actions on websites as the user without the user clicking anything. Google and Microsoft fixed the flaws assigned to them, but the research shows that browser add-ons with broad permissions can turn increasingly capable AI features into a route for stealing information or acting in someone’s name.
