Claude Fable 5 stays free for paid users until July 19 as Anthropic buys more time

Anthropic has extended free Claude Fable 5 access for paid subscribers until July 19, giving Pro, Max, Team, and eligible Enterprise users another week before usage credits are required beyond the promotional allowance.
KEY POINTS
  • 01Anthropic has extended paid subscriber access to Claude Fable 5 until July 19, 2026 at 11:59:59 PM PT.
  • 02The promotion applies to Claude Pro, Max, Team, and premium seats on seat-based Enterprise plans where enabled by the organization.
  • 03Paid users can use Fable 5 for up to 50% of their weekly subscription limits at no extra cost, but Anthropic says it uses the weekly limit faster than other Claude models.
  • 04Once users reach the 50% weekly Fable 5 allowance, they can continue using Fable 5 with separately billed usage credits or switch to another Claude model within their remaining plan limits.
  • 05The promotion does not apply to Free users, standard seats on seat-based Enterprise plans, usage-based Enterprise plans, or API usage.

Anthropic has extended access to Claude Fable 5 for paid subscribers until July 19, 2026 at 11:59:59 PM PT. The model was previously included in Pro, Max, Team, and premium Enterprise subscriptions only through July 7, then extended to July 12 before this latest extension. Anthropic also extended the 50% increase to Claude Code weekly usage limits through the same date.

The promotion lets eligible paid users use Fable 5 for up to 50% of their weekly subscription limits at no extra cost. Fable 5 uses the same weekly usage pool as other Claude models, and Anthropic warns that it uses that weekly limit faster than other models. Once users hit the 50% weekly Fable 5 allowance, they can either continue with separately billed usage credits or switch to another Claude model within their remaining plan limits.

The extension applies to Claude Pro, Max, Team, and premium seats on seat-based Enterprise plans where enabled by the organization. Fable 5 is available across Claude on the web, Claude Mobile, Claude Desktop, Claude Cowork, Claude Code, Claude Design, Claude for Microsoft 365, Claude for Teams, and Claude Tag, with Claude Code requiring version 2.1.170 or later. The promotion does not apply to Free users, standard seats on seat-based Enterprise plans, usage-based Enterprise plans, or API usage.

  • The promotion is not a separate free quota because Fable 5 draws from the same weekly usage pool as other Claude models and can consume that pool faster.
  • API users are excluded even though Fable 5 remains available across many Claude apps and products, so the extension only helps users working through eligible Claude subscription interfaces.
  • Anthropic has extended the Fable 5 subscription promotion multiple times and says the model is not permanently leaving subscriptions, with restoration planned when the company has enough compute.
  • The same July 19 deadline also applies to the 50% increase in Claude Code weekly usage limits, making that date important for users who rely on Claude Code as well as Fable 5.

Anthropic has extended access to its Claude Fable 5 model for paid users until July 19, after previously planning to end the included access earlier. This affects people and organizations using Claude Pro, Max, Team, and certain Enterprise plans, who can keep using Fable 5 for part of their weekly allowance without extra payment. It matters because Fable 5 uses up that allowance faster than other Claude models, and once users hit the limit they must either pay separately with credits or switch to another model.

Emerging Threat: (CVE-2026-56291) Balbooa Forms Remote Code Execution via Unauthenticated File Upload

CVE-2026-56291 is a critical, actively exploited unauthenticated file upload flaw in Balbooa Forms for Joomla that can let attackers upload and run PHP files for full remote code execution. Sites using Balbooa Forms 2.4.0 or earlier should update to 2.4.1 immediately and check for compromise.
KEY POINTS
  • 01CVE-2026-56291 is an unauthenticated arbitrary file upload vulnerability in Balbooa Forms, the com_baforms component for Joomla, and is classified as CWE-434.
  • 02The vulnerability affects Balbooa Forms up to and including version 2.4.0 and can allow an anonymous attacker to upload a PHP file into a web-served directory and execute it for remote code execution.
  • 03The flaw has a CVSS v3.1 base score of 9.8 and a CVSS v4.0 base score of 10.0, is listed in CISA’s Known Exploited Vulnerabilities catalog, and is being actively exploited in the wild.
  • 04Balbooa fixed the vulnerability in Balbooa Forms 2.4.1, released on 9 July 2026, but sites that ran affected versions while exposed should also be checked for signs of compromise.
  • 05Recommended actions include inventorying internet-facing Joomla sites, identifying Balbooa Forms installations, blocking script execution in upload directories, monitoring relevant POST requests, auditing Super User accounts, and scanning upload directories for unexpected PHP files.

CVE-2026-56291 is an unauthenticated arbitrary file upload vulnerability in Balbooa Forms, a commercial drag-and-drop form builder for Joomla installed as the com_baforms component. The flaw affects Balbooa Forms up to and including version 2.4.0 and is classified as CWE-434. It has a CVSS v3.1 base score of 9.8 and a CVSS v4.0 base score of 10.0, and the article says it is listed in CISA’s Known Exploited Vulnerabilities catalog and is being actively exploited in the wild.

The vulnerable frontend attachment upload accepts files from anonymous visitors without a login, CSRF token, or extension allow-list. Because the upload handler trusts the caller-supplied filename and Joomla’s built-in filename cleaner does not strip a .php extension, an attacker can upload a PHP file into a web-served directory and then request it in a browser. By default, uploaded files land under images/baforms/uploads/ inside the web root, where they can be served and executed directly. The article states that the practical impact is full remote code execution, which can enable data theft, defacement, backdoors, or pivoting to other systems.

Balbooa fixed the vulnerability in Balbooa Forms 2.4.1, released on 9 July 2026, and any installation on 2.4.0 or earlier should be treated as vulnerable until updated. The article says updating alone is not sufficient because the flaw was exploited before the patch shipped, so exposed sites should be checked for compromise, including unexpected files in the upload directory and unfamiliar administrator accounts. Recommended actions include inventorying internet-facing Joomla sites, identifying Balbooa Forms installations, restricting upload endpoints where feasible, blocking script execution in upload directories, monitoring relevant POST requests, auditing Super User accounts, and scanning for unexpected PHP files.

  • Updating to Balbooa Forms 2.4.1 is not enough by itself because the flaw was exploited before the patch was released, so previously exposed sites need compromise checks as well.
  • The exposed assets may be difficult to identify externally because Joomla can be detected from the internet but extensions such as Balbooa Forms are not always fingerprintable.
  • Risk is concentrated in forgotten or loosely governed public web properties such as campaign sites, registration pages, localized microsites, and older brand or regional sites rather than only in core applications.
  • A practical mitigation before all upgrades are confirmed is to block script execution specifically in upload directories such as images/baforms/uploads/.
  • The upload endpoint can be reachable to any visitor even without a published form or guest setting being enabled, which makes simple assumptions about form visibility unreliable.

A serious flaw was found in Balbooa Forms, a tool used on Joomla websites to build forms, that lets any visitor upload a harmful file and then run it on the website’s server. Public Joomla sites that use Balbooa Forms version 2.4.0 or earlier are affected, especially sites with contact, registration, survey, or file attachment forms. This matters because criminals are already using the flaw to take control of sites, steal data, deface pages, add hidden access for later, or use one hacked site to attack others.
