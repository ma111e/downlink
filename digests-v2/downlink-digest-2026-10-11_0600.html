Emerging Threat: (CVE-2026-107406) NetScaler ADC and Gateway Remote Code Execution via SAML

CVE-2026-107406 is a critical NetScaler ADC and Gateway SAML memory overflow that can enable unauthenticated remote code execution or denial of service on internet-facing appliances. Organizations should urgently identify SAML-configured instances and upgrade to Citrix’s fixed builds, as no workaround is available.
KEY POINTS
  • 01CVE-2026-107406 is a critical memory overflow flaw in NetScaler ADC and NetScaler Gateway that can cause remote code execution or denial of service without requiring privileges or user interaction.
  • 02The issue affects appliances configured as SAML service providers or identity providers, although certain newer build ranges are affected only when configured as identity providers.
  • 03Citrix released fixed builds including NetScaler ADC and Gateway 14.1-73.46 or later and 13.1-64.29 or later, with separate fixed versions for FIPS and NDcPP branches.
  • 04There is no Citrix workaround other than upgrading or removing SAML authentication where it is not required, and end-of-life appliances require migration to supported versions.
  • 05External scans cannot reliably determine whether a NetScaler appliance is vulnerable because build numbers and SAML configuration are generally not visible externally.

CVE-2026-107406 is a critical memory overflow vulnerability in NetScaler ADC and NetScaler Gateway that can enable remote code execution or denial of service. It has a CVSS v4.0 score of 9.5, can be reached over a network, and requires neither privileges nor user interaction. Citrix reported no awareness of unmitigated exploitation at disclosure, and the article states that no public proof of concept had been identified at publication.

The issue applies only to appliances configured as SAML service providers or identity providers, with newer listed build ranges affected only in the identity-provider role. NetScaler systems commonly sit at an organization’s internet-facing access point and broker authentication for applications behind them, making control of an appliance significant. External scans can identify a NetScaler device but generally cannot determine its build number or whether its SAML configuration makes it affected.

Citrix released fixed builds for all affected supported lines, including 14.1-73.46 or later and 13.1-64.29 or later, with separate targets for FIPS and NDcPP variants. There is no workaround other than upgrading or removing unnecessary SAML authentication, while end-of-life appliances require migration to a supported release. The article recommends inventorying internet-facing appliances, checking their SAML settings and exact builds, prioritizing devices with authentication login panels, and watching for unexplained crashes, restarts, or abnormal requests.

  • An internet-facing NetScaler AAA login panel does not prove that SAML is enabled, but it identifies appliances running the authentication layer where SAML configurations reside and should be reviewed first.
  • External exposure data is unusually limited for this issue: every observed asset was identified only at the fingerprint level, with no high-confidence version detections, so scanning cannot separate patched appliances from affected ones.
  • For newer builds in the listed 14.1 and 13.1 ranges, only the SAML identity-provider role is affected, whereas older builds are affected in either SAML role.
  • The 13.1 FIPS and NDcPP branch uses a different build numbering scheme, making its required fixed version easy to misread during remediation.

The article warns about CVE-2026-107406, a serious flaw in NetScaler ADC and Gateway devices that organizations use to provide remote access to applications. Devices using SAML, a sign-in system that lets services verify users’ identities, may let an outsider take control of the device or cause it to stop working. This matters because these devices often sit at an organization’s internet-facing entrance and handle access to many internal applications, so a compromise could affect far more than one server. Organizations need to check which devices use this sign-in setup and install Citrix’s updated software, because there is no simple temporary fix.
