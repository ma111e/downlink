Microsoft is rolling out Linux container support to WSL

Microsoft has made WSL Containers generally available, adding a native Windows CLI and API for building and running Linux containers without relying on separate container tooling. The release adds enterprise controls through Defender for Endpoint and Intune, while Docker Compose-compatible support is planned.
KEY POINTS
  • 01Microsoft has made WSL Containers generally available, allowing users to build, run, and deploy Linux containers on Windows through the new wslc.exe command-line tool or its container.exe alias.
  • 02The general availability release adds container restart, file copy, health check, network connection management, real-time event, mount, and configurable storage-location capabilities.
  • 03WSL Containers integrates with Microsoft Defender for Endpoint so security teams can view container process, file, and network activity and connect it to the Windows host.
  • 04Microsoft Intune can disable WSL Containers or restrict developers to container images from administrator-approved registries.
  • 05Microsoft is developing Docker Compose-style support intended to allow wsl compose up to work with existing compose.yaml files unchanged.

Microsoft has made WSL Containers generally available, extending Windows Subsystem for Linux beyond running Linux distributions. Users can install the feature with wsl --update and use the new wslc.exe command-line tool, or its container.exe alias, to build, run, and deploy Linux containers on Windows. A WSL Containers API also lets native Windows applications launch and interact with Linux containers programmatically.

The release adds capabilities that were unavailable during preview, including container restarts, file copying, health checks, network connect and disconnect commands, real-time events, mount support, and configurable storage locations. WSL Containers integrates with Microsoft Defender for Endpoint to expose container process, file, and network activity, while Microsoft Intune can disable the feature or restrict image downloads to approved registries. Microsoft says VS Code Dev Containers, Aspire, and the VS Code Containers extension support WSL Containers, and it is working toward wsl compose up compatibility with existing compose.yaml files.

  • WSL Containers expands WSL beyond running Linux distributions by positioning it as a native Windows option for building, running, and deploying Linux containers.
  • The enterprise controls combine activity visibility through Microsoft Defender for Endpoint with prevention controls in Intune, including the ability to disable the feature or limit image downloads to approved registries.
  • Support from VS Code Dev Containers, Aspire, and the VS Code Containers extension indicates that WSL Containers is being integrated into existing developer workflows rather than operating only as a standalone command-line tool.
  • Microsoft says WSL Containers can provide up to twice the performance when Linux environments access Windows files, while it continues work on underlying networking and cross-operating-system file performance.
  • Docker Compose-style support remains a planned capability, meaning the requested wsl compose up workflow is not yet available.

Microsoft has released a new Windows feature that lets people create and run packaged Linux applications, called containers, directly through the Windows Subsystem for Linux. Developers can use it for tasks such as local AI work, while businesses can monitor what these packages do and limit downloads to approved sources. This matters because it makes Linux application packaging easier to use on Windows while giving organizations more control and visibility over potentially risky software.

OPEN SOURCE ↗

Microsoft’s general availability release of WSL Containers is relevant to security professionals because it introduces new container execution, monitoring, and policy-control capabilities on Windows. It is a concrete product release with enterprise implications, but it does not report active exploitation, a breach, or an urgent security patch.
